# PET v2 — 前端设计规范（v0.15）

> v0.6（2026-11-23）：口语 5+10+15 与返回按钮、听力纯播放器与当前实现对齐。
> **token 实际值以 `frontend/src/tokens.css` 为唯一来源**，本文件只描述语义与用法。

> 设计基调：**「绿野成长」**——绿色系、儿童向（小学生 8–12 岁）、高设计感、AI 可执行。
> 本规范是 AI 生成前端的硬约束：**所有颜色/字号/间距只能引用 Design Token，禁止写死 hex**。

---

## 1. 设计原则（六条，AI 生成 UI 时逐条自检）

1. **儿童友好（Kid-first）**：大按钮（触控目标 ≥ 44px）、大字号、圆角柔和、图标表意优先于文字；避免成人后台的密集表格感。
2. **成长感（Growth）**：绿色主色象征成长；用进度环、徽章、连胜天数等正向反馈元素，弱化"错误/分数"的负面感。
3. **一次一件事（Focus）**：每屏一个主任务；做题界面无干扰（隐藏导航、只留题目+提交）；信息分层靠卡片和留白，不靠分割线堆砌。
4. **可预期（Consistent）**：同类交互全站一致——按钮层级、反馈动效、朗读按钮位置都固定模式，孩子形成肌肉记忆。
5. **有活力但不闹（Playful, not noisy）**：插画/表情点缀限 1–2 处/屏；动效 150–250ms、只做位移+透明度，不做夸张弹跳。
6. **具象优先（Concrete over abstract）**：进度优先用"可数、可点、能看出断没断"的表达（如 30 天格子墙），
   百分比进度条只作辅助。孩子能数清的东西才有意义；抽象百分比不产生成就感。
   - 天数 ≤60 一天一格，>60 一格一周（避免排出上百个点）。
   - 计划按连续天数推进，第一个没做的天就是"今天"，所以只需三态：已完成 / 今天 / 还没学。

## 2. Design Tokens（`tokens.css`，唯一色彩来源）

### 2.1 色彩（与 `tokens.css` 对齐，2026-11-23）

```css
:root {
  /* 品牌绿 */
  --c-primary: #16a34a;         /* 主绿：填充（配白字需 ≥18px 加粗）、图形 */
  --c-primary-strong: #15803d;  /* 深绿：文字/链接/填充主按钮（5.05:1） */
  --c-primary-soft: #e7f6ec;    /* 浅绿：标签底、选中态背景 */
  --c-mint-bg: #f2faf5;         /* 薄荷白：行悬停、daycard 底 */

  /* 功能色（点缀，不与绿争抢） */
  --c-accent: #d97706;          /* 暖橙：答错反馈、提示、断签（答错不惩罚，不用红） */
  --c-accent-soft: #fff7ed;
  --c-danger: #dc2626;          /* 红：仅「删除」等破坏性操作按钮 */
  --c-danger-soft: #fef2f2;
  --c-info: #2563eb;            /* 蓝：信息提示 */
  --c-info-soft: #eff6ff;

  /* 中性（偏冷，拉开与绿的层次） */
  --c-text: #16211c;  --c-text-2: #64756c;  --c-text-3: #94a49b;
  --c-card: #ffffff;  --c-bg: #f6f9f7;
  --c-line: #e6eee9;  --c-line-strong: #d3e0d8;  --c-surface: #ffffff;

  /* 圆角（v0.2 收敛为四档） */
  --r-sm: 10px; --r-btn: 14px; --r-card: 20px; --r-xl: 24px; --r-pill: 999px;

  /* 阴影（冷绿黑打底，三档，低对比） */
  --shadow-1: 0 1px 2px rgba(16,40,28,.04), 0 4px 12px rgba(16,40,28,.05);
  --shadow-2: 0 2px 6px rgba(16,40,28,.06), 0 12px 28px rgba(16,40,28,.08);
  --shadow-3: 0 8px 20px rgba(16,40,28,.10), 0 24px 48px rgba(16,40,28,.12);
  /* 旧名兼容：--shadow-card / --shadow-sm = --shadow-1 */

  /* 动效 */
  --dur-1: 120ms; --dur-2: 200ms; --dur-3: 300ms;
  --ease-out: cubic-bezier(.2,.8,.2,1);
  --ease-spring: cubic-bezier(.34,1.4,.64,1);

```

深色模式：v2 首版**不做**（孩子白天使用为主），token 结构已预留，后续可加 `.dark` 覆盖。

### 2.2 字号（移动优先，远看清晰）

| Token | 值 | 用途 |
|-------|-----|------|
| --fs-display | 28px/800 | 板块标题（h1） |
| --fs-title | 22px/700 | 卡片标题、题目 |
| --fs-body | 16px/400 | 正文、选项（不低于 16） |
| --fs-sub | 14px/400 | 辅助说明、时间戳、行内次级文字 |

更小的字号（11–13px）只用于徽章/角标，允许在局部写死，但同一语义全站要一致。

字体：英文 **Nunito**（自托管 `public/fonts/nunito-latin.woff2`，可变字重 400–800，39KB，`font-display: swap`），
中文回落系统圆体。栈：`--font-base: "Nunito", system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`。
单词展示用 `--font-word`（Nunito 优先，回落 Georgia）。
数字一律 `font-variant-numeric: tabular-nums`（类名 `.tnum`），避免进度/计数跳动。

**对比度红线**：`#16A34A` 对白仅 3.4:1，**只能做填充**（配白字需 ≥18px 加粗）或图形；
正文/链接/小字一律用 `#15803D`（5.3:1）。`#22C55E`（2.3:1）只能做描边、图标、进度环，**禁止承载文字**。

### 2.3 间距与布局

- 4px 网格：间距只用 4/8/12/16/24/32。
- 内容最大宽度：学习页 720px，首页 960px，居中。
- 触控目标：≥ 44×44px；选项卡片 ≥ 56px 高。

## 4. 页面骨架规范（与当前实现一致）

- **布局层**：`AppLayout`——左侧 `SiderNav`（学科常驻：英语五板块——单词/阅读/语法/听力/口语——加语文/数学占位），
  右上角用户菜单（设置 / 管理，admin 才显示）；内容区顶部面包屑 + 三级页签条（教材/计划/错题等）。
- **内容宽度**：默认 960；`meta.width: "narrow"` = 720（沉浸式作答/对话页）；页面内一律 `width:100%`，宽度只由布局层决定。
- **做题页**：沉浸式——顶部「退出 + 分段进度条」；题目居中大字；选项大卡纵向排列；键盘 1–4 选择、Enter 下一题。
- **反馈区**：提交后原地展开（图标+标题+说明），配「听发音/听整句」；答错暖橙不打分羞辱。
- **阅读**：首页按教材折叠（Trainer 1/2），每套一行「测整套」+ 每个 Part 一行「学习/测验」；
  计划、错题、语法都是独立页签/板块，不再内嵌在首页。
- **口语**：计划 1–90 天（格子墙）；每日入口只有跟读 5 分钟 / 造句 10 分钟 / 自由对话 15 分钟；
  对话页内即时优化 + 结束 5 分钟复盘（无独立复盘页）；161 场景独立题库页签；子页统一 `BackButton`。
- **数学**：课程首页（教材 / 学习进度两页签）→ 年级教材（三年级大徽章）→ 视频页（沉浸式、面包屑两级）；
  后续年级在首页用虚线卡占位「即将上线」，上线后自动替换为可进入的大卡。
- **管理后台**：页头（保存状态胶囊，仅配置页显示）+ 四格概览 + 药丸页签（AI 加词/口语对话/发音评测/账号与邀请码/用量）。
- **空态**：空态与创建表单分离——空态只给一句说明 + 一个主动作按钮。

## 5. AI 生成约束（跨机器开发时的执行细则）

1. 颜色/字号/圆角/阴影/动效**只引用 `frontend/src/tokens.css` 的 var()**，禁止内联 hex（精读成分五色等**语义色**除外，见 §3）。
2. UI 框架是 Naive UI，不要手写它已有的基础组件；主题统一走 `theme.ts` 的 themeOverrides，不要在页面里覆盖 Naive 内部 token。
3. 新页面先过 §1 六条原则自检，再对照 §3 选既有模式；页签路由加进 `router/index.ts` 对应 `*_TABS`。
4. 图标统一线性 SVG（currentColor），**不用 emoji**。
5. 动效 120–300ms、ease-out、只动 transform/opacity；`prefers-reduced-motion` 全站已降级，新增动画自动生效。
6. 任何页面在 390px 宽度不得横向滚动。
7. **改动后必跑的验收清单**（另一台机器同样适用）：
   ```bash
   cd frontend && npx vue-tsc --noEmit        # 类型
   cd frontend && npx vitest run              # 前端单测（core/ + stores/）
   cd backend  && .venv/bin/python -m pytest -q   # 后端单测
   python tools/check_tokens.py               # CSS 变量引用 vs :root 定义（写错不报错，必须扫）
   # 溢出检查：先起 dev server（frontend: npx vite --port 5178），再：
   node tools/check_overflow.js http://localhost:5178   # 20 路由 × 3 视口（1440/820/390），退出码非 0 = 有溢出
   ```
   `tools/check_overflow.js` 用打桩 API 免真实账号，依赖 `package.json`（仓库根）里的 playwright；
   首次在新机器运行需 `npm i`（仓库根）+ `npx playwright install chromium`。
