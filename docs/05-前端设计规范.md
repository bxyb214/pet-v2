# PET v2 — 前端设计规范（v0.1，待确认）

> 设计基调：**「绿野成长」**——绿色系、儿童向（小学生 8–12 岁）、高设计感、AI 可执行。
> 本规范是 AI 生成前端的硬约束：**所有颜色/字号/间距只能引用 Design Token，禁止写死 hex**。

---

## 1. 设计原则（五条，AI 生成 UI 时逐条自检）

1. **儿童友好（Kid-first）**：大按钮（触控目标 ≥ 44px）、大字号、圆角柔和、图标表意优先于文字；避免成人后台的密集表格感。
2. **成长感（Growth）**：绿色主色象征成长；用进度环、徽章、连胜天数等正向反馈元素，弱化"错误/分数"的负面感。
3. **一次一件事（Focus）**：每屏一个主任务；做题界面无干扰（隐藏导航、只留题目+提交）；信息分层靠卡片和留白，不靠分割线堆砌。
4. **可预期（Consistent）**：同类交互全站一致——按钮层级、反馈动效、朗读按钮位置都固定模式，孩子形成肌肉记忆。
5. **有活力但不闹（Playful, not noisy）**：插画/表情点缀限 1–2 处/屏；动效 150–250ms、只做位移+透明度，不做夸张弹跳。

## 2. Design Tokens（`tokens.css`，唯一色彩来源）

### 2.1 色彩

```css
:root {
  /* 品牌绿 */
  --c-primary: #16a34a;      /* 主绿：按钮、导航激活、进度 */
  --c-primary-strong: #15803d; /* 深绿：hover / 强调文字 */
  --c-primary-soft: #dcfce7; /* 浅绿：卡片底、选中态背景 */
  --c-mint-bg: #f0fdf4;      /* 页面背景（薄荷白） */

  /* 功能色（点缀，不与绿争抢） */
  --c-accent: #f59e0b;       /* 琥珀：徽章、连胜、提示 */
  --c-danger: #ef4444;       /* 错误：仅语义错误反馈 */
  --c-info: #0ea5e9;         /* 音频/听力相关 */

  /* 中性 */
  --c-text: #1f2937;
  --c-text-2: #6b7280;
  --c-card: #ffffff;
  --c-line: #e5e7eb;

  /* 圆角 / 阴影 */
  --r-card: 16px;
  --r-btn: 12px;
  --r-pill: 999px;
  --shadow-card: 0 2px 8px rgba(22, 163, 74, 0.08);
  --shadow-pop: 0 8px 24px rgba(31, 41, 55, 0.12);
}
```

深色模式：v2 首版**不做**（孩子白天使用为主），token 结构已预留，后续可加 `.dark` 覆盖。

### 2.2 字号（移动优先，远看清晰）

| Token | 值 | 用途 |
|-------|-----|------|
| --fs-display | 28px/700 | 板块标题、完成庆祝页 |
| --fs-title | 20px/600 | 卡片标题、题目 |
| --fs-body | 16px/400 | 正文、选项 |
| --fs-sub | 13px/400 | 辅助说明、时间戳 |

字体栈：`system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`；英文单词展示可用 `Georgia` 衬线提升辨识度（词卡场景）。

### 2.3 间距与布局

- 4px 网格：间距只用 4/8/12/16/24/32。
- 内容最大宽度：学习页 720px，首页 960px，居中。
- 触控目标：≥ 44×44px；选项卡片 ≥ 56px 高。

## 3. 组件模式（全站固定，AI 不自创样式）

| 组件 | 规范 |
|------|------|
| 主按钮 | `--c-primary` 填充、白字、`--r-btn`、hover 深绿；提交/确认用 |
| 次按钮 | 白底绿字绿边；取消/返回用 |
| 选项卡 | 白卡 + `--shadow-card`，选中态 `--c-primary-soft` 底 + 2px 绿边 |
| 进度环 | SVG 圆环，`--c-primary`；用于今日计划完成度 |
| 反馈条 | 答对=浅绿底+✓；答错=浅红底+鼓励文案（"再试一次！"，不打分羞辱） |
| 朗读按钮 | 固定圆形图标按钮（🔊），位置固定在反馈区右侧 |
| 徽章 | pill 形，`--c-accent` 系，用于连胜/成就 |
| 折叠组 | 白卡头部 + 箭头旋转 180° 动效 200ms |

## 4. 页面骨架规范

- **首页**：顶部问候语（"今天也加油！"）+ 今日计划进度环 → 五个板块入口卡（大图标卡，2 列网格）→ 错题提醒条（如有待复习）。
- **做题页**：沉浸式——隐藏全局导航，顶部只留「退出」+ 进度点（●●○○）；题目居中大字；选项大卡纵向排列；底部固定提交按钮。
- **反馈区**：提交后原地展开，答对浅绿庆祝（图标+「听发音/听整句」按钮），答错浅红提示+正确答案展示。
- **口语跟读页**：波形/音量可视化 + 大录音按钮（按住说话式），评分结果逐词着色（绿=好 / 琥珀=待改进）。
- **管理后台**：沿用同套 token，但布局可表格化（成人使用），主色不变。

## 5. AI 生成约束（写进 AGENTS.md 的执行细则）

1. 只用 §2 token 与 §3 组件模式，禁止内联 hex、禁止引入第三方 UI 库（组件手写，量小可控）。
2. 新页面/新组件先对照 §1 五条原则自检，再对照 §3 模式选择既有样式。
3. 图标统一用一套开源线性图标（建议 lucide，单色 currentColor），不混用多套风格。
4. 动效统一封装 `useTransition` 模式：150–250ms、ease-out、只动 transform/opacity。
5. 任何页面在 320px 宽度下不得横向滚动（iPad/手机预留，见功能清单 C4 待确认项）。
