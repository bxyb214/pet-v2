## 文档约定

1. **编号固定**：顶层 `01`–`07` 不再重排；新增专题用描述性文件名，放对应目录。
2. **01 冻结**：需求决议不重开；实现口径变化记在 `04` 的变更记录。
3. **05 的 token**：以 `frontend/src/tokens.css` 为唯一来源，文档只描述语义与用法。
4. **06 唯一**：部署、备份、迁移都写这里，不再新增根级 `DEPLOY.md`。
5. **功能开发**：按 03 的七阶段，产出 `dev/{feature}/01-requirements.md`、`02-design.md`、`99-self-review.md`；
   多步迭代用 `-step2` 后缀。完成的文档保留，不删除。
6. **归档**：被取代的整体方案移入 `archive/`，文件名加日期前缀，并在文首注明替代文档。
7. **链接**：文档间用相对路径；中文文件名可保留。
8. **不写敏感信息**：密钥、密码、内网 IP、邀请码一律不进文档与 git。
