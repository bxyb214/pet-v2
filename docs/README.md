## 文档约定

1. **编号固定**：顶层 `01`–`08` 不改号；新增专题用描述性文件名。
2. **01 冻结**：需求决议不重开；实现口径变化记在 `04`。
3. **05 的 token**：以 `frontend/src/tokens.css` 为唯一来源，文档只描述语义与用法。
4. **06 唯一**：部署、备份、迁移都写这里，不再新增 `DEPLOY.md`。
5. **不保留过程文档**：不再建 `docs/dev/`、`docs/archive/`；历史决策查 git history。
6. **链接**：文档间用相对路径；中文文件名可保留。
7. **不写敏感信息**：密钥、密码、内网 IP、邀请码一律不进文档与 git。
