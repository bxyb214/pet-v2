## 1. 组件库选型（推荐：Naive UI）

| 候选 | 版本(2026-11) | 维护 | 优势 | 短板 |
|---|---|---|---|---|
| **Naive UI ✅推荐** | 2.45.3 | 活跃（图森未来） | **100% TypeScript、类型安全主题系统（themeOverrides 直接映射我们的绿野 token）**、90+ 组件按需 tree-shaking、无全局样式污染、颜值高适合 C 端 | 国内资料量少于 Element Plus |
| Element Plus | 2.14.8 | 活跃 | 生态最大、组件最全、中文资料多 | 视觉偏传统后台感、主题定制靠 CSS 变量较绕、体积大 |
| TDesign Vue Next | 1.20.5 | 活跃（腾讯） | 腾讯体系、设计规范完整 | 组件数量与灵活度中等 |
| Arco Design | 2.58 | 一般 | 字节企业级 | 社区活跃度偏低 |

**推荐理由**：本项目是给小学生用的 C 端产品，需要「绿野成长」品牌感的深度定制——Naive UI 的 `n-config-provider + themeOverrides` 是**类型安全的 JS 对象**，能把我们现有 `tokens.css` 的绿色系（--c-primary #16a34a 等）直接喂进去，全局圆角/字号/主色一处改全局生效；且按需引入不拖累打包体积。**业务逻辑（Pinia store / 同步引擎 / 合并语义）零改动，只重构视图层与路由。**

## 3. 布局骨架

```
┌──────────────────────────────────────────────┐
│ 顶栏：Logo「绿野英语」      🔔   用户名 ▾ 管理 │
├──────────┬───────────────────────────────────┤
│ 侧边栏    │  页内三级 tabs（词库|学习|计划|错题）│
│ ┌──────┐ │                                   │
│ │英语 ● │ │        内容区（max 1080px 居中）    │
│ │语文   │ │                                   │
│ │数学   │ │                                   │
│ ├──────┤ │                                   │
│ │单词   │ │                                   │
│ │阅读   │ │                                   │
│ │听力   │ │                                   │
│ │口语   │ │                                   │
│ └──────┘ │                                   │
└──────────┴───────────────────────────────────┘
```

- **一级学科**：侧边栏顶部大图标块（英语-green / 语文-amber / 数学-blue），点击切换学科
- **二级**：学科下的菜单列表（n-menu，儿童大图标 + 文字）
- **三级**：内容区顶部 n-tabs（如词库页内再嵌 n-tabs 或分段器显示必默/高频/固搭/其他单词）
- 移动端/窄屏：侧边栏折叠为抽屉（n-drawer），平板横竖屏都可用

## 4. 视觉升级（绿野成长 v2）

- 保留：绿色主色 #16a34a、薄荷底色、现有 token 语义；themeOverrides 注入 Naive UI（primary/borderRadius/fontSize 一处配置）
- 加强童趣：卡片圆角加大（16px）、进度用森林/成长隐喻（种子→小树→大树）、答对动效（星星+音效）、空态用插画（n-empty + 自定义图）
- 字号阶梯加大一档（正文 ≥16px，标题 ≥22px），触控目标 ≥44px（平板手指）
- 明暗两套 themeOverrides 就绪（先上浅色）

## 5. 组件落位（Naive UI）
