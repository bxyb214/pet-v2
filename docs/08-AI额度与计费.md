# 08 · AI 额度与计费

> 当前状态：**已实施**（2026-11-26 改为一次性总额度）。口语教学设计见 [07](07-口语实时对话方案.md)；
> 功能编号见 [04](04-功能清单.md) 的 M4–M8、S10、S16；接口与数据模型见 [02](02-技术架构.md)。

## 1. 原则

1. **单词、阅读、听力与中文建议的发音不调用付费 AI**：走 NAS 本地 Piper TTS（英/中双音色，固定内容预生成 + 按需缓存），失败时回退浏览器 `speechSynthesis`/`zh-CN`；边际成本为 0。
2. **口语是唯一持续产生费用的板块**：Realtime、腾讯 SOE、Qwen Chat 三类接口；普通云端 TTS 已停用，只保留跟读「听示范」的 Qwen 例外（免费、不记账）。
3. **口语模块对全部账号开放；AI 权限按账号开通，另有一笔一次性总额度**：新注册普通账号默认不开通，管理员在后台按需开启；开启后默认 ¥0.50，用完暂停付费 AI，管理员可调高。
4. **服务端闸门是唯一安全边界**：前端置灰只负责提示，不阻止绕过。
5. **账单是估算**：用于预算与对账参考，不替代供应商账单。
6. **管理员账号不受总额度限制**：仍记账并在管理页展示用量，避免管理员把自己锁死。

## 2. 权益分层

| 能力 | 普通用户 | 管理员 |
|---|---|---|
| 口语计划、题库、句子库、页面浏览 | ✅ | ✅ |
| 本地/浏览器朗读、静态单词/听力音频 | ✅ | ✅ |
| 手动加词、本地练习 | ✅ | ✅ |
| 跟读评分（SOE） | 需开通 AI | ✅ 不限 |
| 自由对话（Realtime） | 需开通 AI | ✅ 不限 |
| 跟读「听示范」（Qwen，缓存） | ✅ 免费不记账 | ✅ 免费不记账 |
| 其他示范音 / 中文建议朗读（本地 TTS） | ✅ 免费 | ✅ 免费 |
| `improve` / `help` / `check` / `review` / 画像 | 需开通 AI · 扣总额度 | ✅ 不限 |
| AI 加词补全（`enrich`） | 需开通 AI · 扣总额度 | ✅ 不限 |

未开通 AI 权限（新账号默认）或总额度用尽时：

- 口语板块**不再整页展示「付费 AI 未启用」提示卡**；只把跟读评分、实时对话、造句转写/点评等付费按钮置灰，点击时提示
  **「此功能需要 AI 权限，请联系小淏开通。」**；额度用尽时提示
  **「AI 总额度已用完，免费功能仍可用；需要更多额度请联系小淏。」**
- 跟读「听示范」走 Qwen（登录即可、免费不记账），其余示范音、SOE 中文建议与单词/阅读朗读走本地 TTS（免费）；本地未启用或失败时才回退浏览器朗读；
- 跟读仍可听可读，只是不请求 SOE 评分；造句可看/听标准答案，单词/阅读/听力题库不受影响；
- 对话中的「怎么说？」与「帮我改」同样置灰并提示原因，不发起付费请求。

## 3. 额度模型

- 开通 AI 权限后，每个账号一笔**一次性总额度**，不按日/月重置；用完即停用，管理员调高后可继续。
- 全局默认存 `app_cfg['ai.budget']`，用户可单独覆盖：

```json
{
  "credit_milli": 500,
  "alert_ratio": 0.8,
  "hard_stop": true,
  "currency": "CNY"
}
```

- 单位统一 `0.001 元`，与 `usages.est_cost_milli` 一致；默认 ¥0.50。
- 已用 = 该账号历史 `usages.est_cost_milli` 累计（含升级前的历史，迁移时会给存量账号补足一笔新的 ¥0.50）。
- 管理员账号在服务端直接放行，不消耗也无法被总额度拦截；用量照常统计。

## 4. 闸门与硬停用

所有付费接口统一依赖 `require_paid_ai(user, db)`：

1. `ai_enabled = false` → **403 `AI_NOT_ENABLED`**，提示找小淏开通。
2. 累计已用 ≥ 总额度且非管理员 → **429 `AI_CREDIT_EXHAUSTED`**，提示需管理员增加额度。
3. 否则放行，并在响应中带 `remaining_milli` 供前端提示。

| 免费（不查额度） | 付费（走闸门） |
|---|---|
| `/speak/plan` `/speak/days` `/speak/log` `/speak/time*` `/speak/review/due` `/speak/review/grade` `/speak/tts/local` `/speak/tts/demo` | `/speak/sdp` `/speak/soe_url` `/speak/tts` `/speak/improve` `/speak/help` `/speak/check` `/speak/review` |
| `/speak/boot`（shadow，不生成画像） | `/speak/boot`（talk，生成画像） |
| `/words/custom` 手动增删改 | `/words/custom/enrich` |

**Realtime 硬停用**：

- `/speak/sdp` 放行前计算剩余额度可支撑的最大秒数，返回 `max_session_sec`；管理员固定 30 分钟上限。
- 前端 80% 提示；到达 `max_session_sec` 自动结束并进入复盘。
- 正常结束由 `/speak/session_end` 结算；中途关页用 `sendBeacon` 补报。
- 服务端记录会话开始时间；超过 30 分钟未收到结束按预估上限补记。
- 允许一次会话轻微超支，但下一次付费调用立即 429。

## 5. 告警

| 阈值 | 用户端 | 管理端 |
|---|---|---|
| 80% | 顶部黄色横幅：「AI 总额度已用 80%，用完将暂停付费功能」 | 用户行黄色，`alert_stage=1` |
| 100% | 红色横幅：「AI 总额度已用完，免费功能仍可用」 | 用户行红色，`alert_stage=2` |
| 未开通 | 付费按钮灰色可点击，点击提示联系小淏开通（不再展示整页提示卡） | 用户行显示「未开通」 |
| 管理员不限 | 不弹额度横幅 | 用户行显示「管理员 · 不限额度」 |

- 告警按账号、阶段去重（`period=total`、`period_key=all`），每个阶段一生只记一次。
- 暂无邮件/短信，先做站内横幅 + 管理端列表。
- 管理端可清除告警、调整额度、查看明细；升级迁移会清空旧的日/月告警。

## 6. 计量

表 `usages` 按人按天记录：Realtime 秒数、文本 token、SOE 次数、LLM token、
TTS 次数与字符、缓存命中、预估费用 `est_cost_milli`。

记账点全在服务端：

- Realtime：会话关闭按前端上报时长折算（`sendBeacon` 与正常结束按 `session_id` 幂等）；
  30 分钟未结束按上限补记。
- SOE：每签发一次 WSS URL 计 1 次。
- LLM：按响应 usage 记账；`enrich_word` 同样记录。
- TTS：未命中缓存才计字符；命中缓存不计费。`/speak/tts/demo`（跟读示范）始终免费且不写 `usages`，成本由管理员承担。
- 单价存 `app_cfg`；`est_cost_milli` 每次累加后按当前单价重算；总额度已用按全部历史行汇总。

## 7. 管理后台

顶层四块：

```text
概览        今日花费、告警数、已开通用户数、Provider 状态
AI 配置     LLM / Realtime / TTS / SOE / 单价与默认额度 / 缓存
用户与额度  卡片式账号（AI 权限、额度进度、重置密码）、状态筛选、邀请码
用量与预算  当日、本月、告警、月末预测、CSV 导出
```

约定：

- AI 配置按组独立保存，每组可做连通性测试；不在这里管理账号与个人额度。
- Key 输入框默认密码态，保存后只回显尾 4 位。
- 「用户与额度」顶部汇总账号总数 / 已开通 / 未开通 / 额度告罄，支持搜索与状态筛选；
- 每个账号一张卡：**AI 权限开关**、额度进度条、累计已用 / 总额度 / 剩余；未开通与额度告罄有状态标签；
- 额度弹窗展示累计已用、当前总额度、剩余，支持 +0.5 / +1 / +2 元快捷加额与「跟随默认」；留空 = 全局默认；
- 新注册普通账号默认未开通 AI，管理员按需打开开关；管理员账号显示「不限额度」，开关仍可关闭其 AI；
- 邀请码作为次级面板放在账号列表之后；
- 清缓存等危险操作二次确认。

## 8. 用户端 AI 计费

- 非管理员：设置页 →「AI 计费」，独立页 `/settings/usage`。
- 展示日/周/月/年预估费用、总额度已用 / 额度、所选月逐日明细；只读当前登录用户。
- 管理员在该页显示「不受总额度限制」。
- 接口 `GET /api/v1/usage/me?month=YYYY-MM`。

## 9. TTS 缓存

- 本地 TTS 缓存键 `sha1(engine + voice + speed + cache_version + normalized_text)`；跟读示范 Qwen 为 `sha1(model + voice + text)`，两者不串味。
- 默认上限 1024 MB，按 mtime LRU；本地 GET 命中时节流 touch mtime。
- 静态 URL + `immutable` 缓存头；本地合成不计费；跟读示范 Qwen 不记账，但首次未命中会真实产生少量费用，命中后为 0。
- 管理页可查看与清理；固定内容用 `tools/build_tts.py` 预生成（Tier A 约 220 MB），清空缓存后需重跑；示范音下次播放重新合成。
- 改音色/语速/规范化规则时升 `speak.local.cache_version`，强制生成新音频。

## 10. 配置与数据

- `users`：`ai_enabled`（新注册普通账号默认关闭，管理员按需开启；管理员账号默认开启）、`ai_credit_milli`（一次性总额度覆盖，NULL=全局默认）。
  旧列 `ai_daily_budget_milli` / `ai_monthly_budget_milli` 保留在库中但不再使用。
- `app_cfg`：`ai.budget`（`credit_milli` / `alert_ratio` / `hard_stop`）、各 Provider Key/模型/端点、
  `speak.tts_cache`、`speak.local`（`enabled/engine/voice/voice_zh/speed/sidecar/max_chars/cache_version/rate_per_min`）、
  `usage.prices`（含 `tts_per_kchar`，仅按需估算参考；跟读示范不记账）。
- `usage_alerts`：按 `(user, period='total', period_key='all', stage)` 去重。
- `ai_sessions`：Realtime 会话跟踪（`open/closed/expired`）。
- `speak` 权限位已移除；口语对所有登录用户开放，付费只由 `ai_enabled` + 总额度控制。
