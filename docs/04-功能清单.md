# PET v2 — 功能清单（v2.0）

> 需求基线 `docs/01` 已冻结。本清单描述**当前已实现能力**；过程性变更记录由 git history 承载。
> 编号：H=首页/导航，V=词汇，R=阅读，L=听力，S=口语，P=计划，U=用户/同步，M=管理/统计，C=通用。

## 核心能力摘要

1. **多学科/多课程架构**（H1/H3）：已接入英语（PET / KET 四板块，语法在阅读下）与数学（李永乐一课通关）；学科 → 课程 → 教材三级，**同一时间只学一门**，在个人中心选择。
2. **错题本 = 记忆曲线间隔重复**（V6/V7）：错题按记忆曲线安排重复（1/2/4/7/15 天间隔），间隔重复达标后该词才标记「全会」移出错题本；dims 维度记账保留。错题本条目展示样式重新设计。
3. **计划时长可选**（V1/P1）：天数由用户任意选择（如 30/40/45），确认后生成。
4. **发音策略分层**（V8/C2/S2）：默认全部走 NAS 本地 Piper TTS（sidecar，英/中双音色，固定内容预生成 + 按需缓存），未命中现合成时播放按钮转圈、最多等 5s，超时或未启用/失败才回退浏览器 `speechSynthesis`；例外：跟读「听示范」与造句 AI 示范句走 Qwen TTS（磁盘缓存、免费不记账，失败回退本地/浏览器；造句示范句仅账号有 AI 权限时用 Qwen，无权限用本地），口语对话的 AI 原声由 Realtime 模型直接提供。SOE 评分后的中文改进建议自动用本地中文音色朗读。普通云端 TTS 停用，TTS 费用只剩示范首次合成。
5. **随机测试**（V10）：错题本权重更高，后期巩固。
6. **配置管理页面**（S5/M2）：所有 Key 类配置存服务端配置（管理页可改），不在代码/环境变量里散落（环境变量只留 JWT secret 等基础设施项）。
7. **用量统计**（M4）：付费接口（Qwen Realtime / SOE / LLM）按用户计量，日/周/月/年统计；本地 TTS 免费；跟读示范 Qwen 免费且不记账。
8. 听力 0.8–1.2 五档倍速（L2）；跟读逐词高亮评分（S6）；词库浏览自学模式（V9）；移动端/iPad 适配（C4）。
9. **首页按学科分区入口**（H2）：英语 / 数学 / 语文各自成区，「今天」条一键续学；支持 iPad 主屏全屏运行（C7）。
