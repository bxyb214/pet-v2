# PET v2 — 功能清单（v1.21）

> 需求基线 `docs/01` 已冻结；本清单持续维护，变更走文末「变更记录」。
> 编号：H=首页/导航，V=词汇，R=阅读，L=听力，S=口语，P=计划，U=用户/同步，M=管理/统计，C=通用。

## 重大改动摘要（相对现状）

1. **多学科/多课程架构**（H1/H3）：顶层目录将扩展为 数学 / 语文 / 英语 等学科；英语下含 KET / PET / FCE / 初中英语，**同一时间只学一门**，在个人中心选择；个人中心还有「学习材料」开关决定显示哪些教材。
2. **错题本 = 记忆曲线间隔重复**（V6/V7）：错题按记忆曲线安排重复（1/2/4/7/15 天间隔），间隔重复达标后该词才标记「全会」移出错题本；dims 维度记账保留。错题本条目展示样式重新设计。
3. **计划时长可选**（V1/P1）：天数由用户任意选择（如 30/40/45），确认后生成。
4. **音频 AI 生成 + 缓存**（V8/C2）：TTS 按需生成，磁盘缓存，nginx 静态服务。
5. **随机测试**（V10）：错题本权重更高，后期巩固。
6. **配置管理页面**（S5/M2）：所有 Key 类配置存服务端配置（管理页可改），不在代码/环境变量里散落（环境变量只留 JWT secret 等基础设施项）。
7. **用量统计**（M4）：付费接口（TTS / Qwen Realtime）按用户计量，日/周/月/年统计；用户看自己的，管理员看全部。
8. 听力 0.8–1.2 五档倍速（L2）；跟读逐词高亮评分（S6）；词库浏览自学模式（V9）；移动端/iPad 适配（C4）。
