# 10 · 前端界面走查报告与优化方案（v0.1 待评审）

> 2026-11-22。走查方式：Playwright 实机截图（1440×900 全页 + 390×844 窄屏）共 20 张，旧系统本地副本同机对比 4 张。
> 截图存 `pet-v2/_work/shots/`（新站）与 `old-L*.png`（旧站）。

---

## 0. 一句话结论

**结构骨架（左侧学科导航 + 三级页签）方向是对的，但"最后一公里"没做完**：内容容器宽度各页不一、移动端全面破损、折叠控件失效、字号与触控目标偏小、全白卡片缺乏层级——导致整体观感像"拼装的原型"，在**移动端可用性**和**儿童友好度**上确实不如旧站。

旧站不是设计得多好（它基本是白卡片 + 蓝按钮的后台风），而是它**每一屏只做一件事、点得到、看得清**。新站信息更全、结构更清晰，但把这几件基本功丢了。

## 2. 问题清单（按严重度）

### P0-1 移动端布局全面破损 ★最严重

**证据**：`m1-words-browse.png`、`m2-speak-home.png`

| 现象 | 根因（代码位置） |
|---|---|
| 侧栏压成 76px 图标条，文字被挤成竖排（"语/文"、"数/学"） | `layouts/AppLayout.vue:160-166` 媒体查询只缩宽度，`.subj` 改 `flex-direction: column` 但 `.s-name` 仍显示；`s-ico` 固定 38px + 容器 76px − padding 16px 只剩 60px |
| 页签"词库/学习/计划/错题"每个字占一行 | `.tabs3` 是 `inline-flex` 且无 `min-width`/`nowrap`，5 个 tab 在 390px 内被 flex 压缩，文字自动换行（`AppLayout.vue:156-158`） |
| 词库表格右侧（释义/掌握度/状态）被裁掉，无法横向滚动 | `n-data-table` 未设 `scroll-x`，父容器 `overflow` 默认可见但列宽被压（`BrowsePage.vue`） |
| 90 天日历挤成数字墙 `1 2 3…101112131415` | `SpeakHome.vue` 用 `grid-template-columns: repeat(15, 1fr)` 固定 15 列，390px 下每列 16px，两位数直接粘连 |
| 入口卡文字一字一行（"跟/读/纠/音"） | `.entries` 固定 `repeat(3, 1fr)`，卡片内 `b` 与 `span` 被压到 60px 宽（`SpeakHome.vue`） |
| 顶栏"管理/退出"竖排 | 顶栏 `gap: 10px` + 用户名过长，`.chip` 无 `white-space: nowrap` |

**判定**：这是"能不能用"的问题。小学生大概率用平板/手机，必须修。

---

### P0-2 内容容器宽度策略分裂（桌面端的"拼装感"来源）

**证据**：`03-words-study.png`（内容卡 510px，右侧 400px 空白）、`13-speak-talk.png`（内容 300px，右侧近 700px 空白）、`17-admin.png`（卡片 760px 停在半空）

代码事实——**同站 6 种内容宽度**：

| 宽度 | 页面 |
|---|---|
| 640px | ReadingQuiz / SpeakReview / SpeakTalk / ListeningReview |
| 680px | QuizPage / SpeakShadow / SentencePage / AddSentencePage / ComingSoon |
| 720px | PlanPage / ListeningHome |
| 760px | ReadingHome / SpeakHome / AdminPage / ListeningPartPage |
| 820px | WordsMistakes / ReadingMistakes |
| 980px | BrowsePage |

叠加问题：
1. `.main` 已经有 `padding: 20px 24px`，页面内部又各自 `padding: 16px` + `margin: 0 auto` → **双重内边距 + 页内居中**，而面包屑/页签是左对齐 → 每页左边缘都不在同一条线上。
2. `.main { max-width: 1120px }` 但没有 `margin: 0 auto`，1440px 屏上右侧留 200px 死白，同时页面又把内容居中到更窄 → 左右白边不对称。

**结论**：这是"看起来不专业"的最大单一原因。必须收敛为**一套容器规则**。

---

### P0-3 折叠控件失效（阅读/听力首页）

**证据**：`06-reading-home.png`、`09-listening-home.png`——Trainer 卡左侧只有一个"·"

- 箭头用字符 `<span class="arrow">▸</span>`（`ReadingHome.vue:40`、`ListeningHome.vue:14`），当前字体栈下该字符渲染异常（极小、偏下）
- 没有 `▶ 展开` 文字按钮，可点击性完全靠猜
- 听力页折叠头部卡片宽度（约 380px）与下方 Test 列表（约 620px）不一致，视觉上像"错位的标签"
- 展开/收起无高度过渡动画，内容"闪现"

顺带：听力页 Test 1–6 全部平铺，6×4=24 行无卡片边界、无分隔线，一眼看不出"一套 = 四个 Part"。

---

### P1-4 字号与触控目标偏小（儿童友好度）

- 表格正文 13px、状态徽标 12px、分页按钮 24px 见方、`换一句 →` 是 12px 文字链
- 目标用户是小学生（PET 约 10–12 岁），正文应 ≥15px、辅助 ≥13px、可点区域 ≥40px 高
- 旧站正文 14–16px、卡片整块可点，这一点旧站做得更好

---

### P1-5 视觉层级贫瘠（"全白卡片症"）

- 所有区块都是 `#fff` 卡 + `1px #e5efe9` 边 + 同一层阴影，卡片里套卡片，**没有一级/二级容器区分**
- 页面背景 `--c-mint-bg` 只在部分页生效，多数页是纯白 → 卡片浮不起来
- 缺少"分区色"：统计卡、教材组、练习区、结果区全是一个样子
- 图标体系三套混用：
  - 侧栏学科：文字块 `ABC` / `文` / `123`
  - 侧栏板块：emoji `📖📚🎧🎤`
  - 统计卡：emoji `📋🔁✅`、`📁☑️⚠️🔥`
  - 同一屏里 emoji 与文字块并存，风格直接撕裂
- 圆角也不统一：卡片 16px、统计卡 16px、按钮 12px、chips 999px、输入框 8px，混用后没有节奏

---

### P1-6 词库表格密度与可读性

**证据**：`02-words-browse.png`

- 行高 33px（儿童点"去学习"极易点错行）
- 掌握度进度条：4px 高、灰色轨道 + 白填充 → **0% 时完全看不见**，用户以为坏了
- 状态徽标"未学"：浅灰底浅灰字，对比度不足（低于 WCAG AA）
- 列宽失衡：音标列被压窄导致 `/əˈkɒməˌdeɪʃn/` 贴边，状态列宽 90px 只放两个字
- 5 个分类 chips 中第 5 个"其他单词（手动上传）0"文字最长却和别的一样小，括号计数风格与前面 `必默 712` 不一致

---

### P1-7 空状态与表单混排（计划页）

**证据**：`04-words-plan.png`

- 计划卡内：🌱 图标 + "还没有计划。输入天数…" 居中，但下方"新计划天数 [30] + - [预览]"同一个视觉带，文字与输入行垂直距离仅 6px，看起来像重叠
- 空状态与创建表单应该分两段：一段空态说明（可带插画），一段"创建计划"操作区（带边框或底色区分）

---

### P1-8 交互反馈不统一

- 页面切换无骨架屏，只有首屏一次 `加载中…` 文本
- 按钮三层（主/次/弱）不统一：有的页 `n-button type="primary"`，有的页自写 `.btn big`，同一功能两种长相
- 成功/失败反馈：保存成功是一行灰字"已保存 ✓"，答题对错是背景色块，风格不统一
- 无 hover 位移/按下缩放这类"手感"细节；旧站的卡片 hover 反而更明显
- `← 返回口语` 是虚线小胶囊（12px），既不像按钮也不像链接

---

### P2-9 信息架构细节

- 面包屑（英语 / 单词 / 词库）与三级页签（词库|学习|计划|错题）**表达同一件事**，重复占两行
- "加句"放在阅读页签里——它是操作而非内容分区，放在页签里语义不对
- 口语"计划/跟读/对话/复盘/造句"5 个页签，但首页本身又叫"计划"，点"计划"页签只是回到当前页，语义绕
- 错题作为三级页签是对的（沿用），但听力"错题"页签与"教材"并列，实际是复习入口，可考虑并入首页卡片 + 独立页保留

### P2-10 长内容页信息密度

- 阅读首页把 42 个语法考点全平铺（`06-reading-home.png`），10 天 × 每天 4–6 个绿胶囊，**首屏就是几百个可点目标**，小学生会晕
- 建议：默认只展开"当前天"，其余折叠；考点胶囊改为两行（编号 + 名称 + 题数），或改成"10 天进度条 + 当天考点"

### P2-11 其它

- 无深色模式（可选，非必须；但 IDE 是 dark，说明用户本地偏好暗色）
- 全站无 favicon 之外的品牌元素（登录页有 🌱，进入应用后品牌感消失）
- 空状态插画缺失（只有 emoji 🎉），微童趣只停留在"绿"

## 3. 优化方案

### 3.1 设计系统：先定规则，再改页面（核心）

**① 容器规范（一次性解决 P0-2）**

```
.main            固定 padding: 24px 28px 56px；max-width 不设（内容页自己控）
.page            统一宽 880px，居中（margin-inline: auto），页内不再加 padding
.page--wide      1120px（仅词库表、管理后台、听力长列表）
.page--narrow    640px（仅答题/对话/复盘的"专注模式"页）
```

规则：**页面宽度只有三档、且必须居中，页内 padding 交给 `.main`**。所有页面删掉自己的 `padding: 16px`。

**② 间距刻度（8pt）**：`4 / 8 / 12 / 16 / 24 / 32 / 48`，禁止出现 6px、10px、14px、22px 这类魔法数字（当前共 11 种间距值）。

**③ 字号刻度（儿童向，整体上移一档）**

| 用途 | 现在 | 建议 |
|---|---|---|
| 页面标题 | 20px | 24px / 700 |
| 区块标题 | 15–16px | 18px / 700 |
| 正文 | 13–14px | 15px / 1.6 |
| 辅助 | 11–12px | 13px |
| 表格正文 | 13px | 15px，行高 48px |

**④ 卡片只留两级**

- L1「区块卡」：白底 + 16px 圆角 + `0 1px 2px rgba(16,40,24,.04)` + `1px solid #e8f0ea`
- L2「内嵌条目」：**不用卡**，用 `8px` 圆角浅底块（`#f6faf7`）或分隔线，杜绝"卡中卡"
- 页面底色统一 `#f7faf8`，让白卡真正浮起来

**⑤ 图标规范（解决三套混用）**

- 统一用 **Naive UI 官方图标集**（`@vicons/ionicons5`，线性 + 2px 描边）替代所有 emoji（保留 🌱/🎉 仅限品牌位与空状态插画）
- 侧栏学科块改用**首字母圆形徽标**（E/C/M）或统一线性图标，不再用 `ABC/文/123` 文字块
- 统计卡图标统一线性 + 同色浅底圆角方块

**⑥ 空状态规范**：插画位（96×96 线性插画）+ 一句说明（15px）+ 一个主动作按钮，垂直居中，不与表单混排。

**⑦ 响应式三档（解决 P0-1）**

| 断点 | 布局 |
|---|---|
| ≥1024px | 侧栏 240px 常驻 + 内容区 |
| 768–1023px | 侧栏收成 64px 图标条（仅图标 + tooltip） |
| <768px | **侧栏变抽屉**：顶栏出现 ☰，点击从左侧滑出全宽导航（含文字）；内容区单列；页签横向可滚动、不换行；表格切卡片列表；日历改 7 列周视图 |

### 3.2 逐项修复清单

| # | 问题 | 具体做法 | 工作量 |
|---|---|---|---|
| 1 | 移动端全面破损 | 侧栏改抽屉（`n-drawer`）+ 768px 断点重写；`.tabs3` 加 `overflow-x:auto; white-space:nowrap; scrollbar-width:none`；表格 `:scroll-x="800"`；日历 <768px 改 `repeat(7,1fr)` 或改"本周 7 天 + 进度条"；入口卡改 1 列 | 1 天 |
| 2 | 容器宽度分裂 | 引入 `.page / .page--wide / .page--narrow` 三档 + 删除各页自带的 padding/margin（19 个文件机械改动） | 0.5 天 |
| 3 | 折叠控件失效 | 换 `n-collapse`（自带箭头、动画、无障碍）或自写：`<ChevronForward>` 旋转 + 整行 `button` + `▶ 展开/▼ 收起` 文字；听力 Test 用二级 `n-collapse` 或卡片分组 | 0.5 天 |
| 4 | 字号/触控偏小 | 按 3.1③ 全局替换 token；表格 `:row-props` 行高 48px；所有可点元素 `min-height:40px` | 0.5 天 |
| 5 | 视觉层级贫瘠 | 页面底色 + 两级卡片 + 统计卡统一线性图标 + 分区色（统计=白卡/练习=浅绿/noise 可选） | 1 天 |
| 6 | 词库表格 | 掌握度条改 `n-progress`（8px、带百分比文字）、状态徽标改 `n-tag`（未学 default / 学习中 info / 已掌握 success）、列宽固定（词 240 / 音标 180 / 释义 flex / 掌握 160 / 状态 100 / 操作 96） | 0.5 天 |
| 7 | 计划页空状态 | 空态块与创建区分离：空态卡（🌱 插画 + 说明 + 主按钮「创建计划」）→ 点击后展开天数输入（`n-collapse-transition`） | 0.3 天 |
| 8 | 交互反馈 | 统一按钮：主 `n-button type=primary size=large`、次 `secondary`、弱 `quaternary`；路由切换加 200ms 骨架；保存成功改 `n-message` 顶部提示；`返回` 改 `n-button quaternary` 带 `←` 图标 | 0.5 天 |
| 9 | 信息架构 | 面包屑只保留"学科/板块"两级（当前页由页签表达）；"加句"从页签移到教材页右下角浮动按钮 + 独立页保留；口语首页页签名改"90 天计划" | 0.3 天 |
| 10 | 阅读 42 考点 | 改"10 天手风琴"：默认展开当前天，其余只显示"第 N 天 · 名词（4 个考点）" | 0.5 天 |
| 11 | 深色模式（可选） | `n-config-provider :theme="darkTheme"` + tokens 双套；跟随系统 | 0.5 天 |

**合计约 6.5 人天**（其中 P0 三项 ≈ 2 天）。

### 3.3 建议实施顺序

1. **P0 修复（2 天）**：容器规范 + 移动端 + 折叠控件 —— 修完这三个，"能不能用"就过关
2. **P1 统一（2.5 天）**：字号刻度 + 两级卡片 + 图标规范 + 表格 + 空状态 + 按钮体系
3. **P2 打磨（2 天）**：信息架构微调 + 阅读考点折叠 + 深色模式（可选）+ 走查复验

每阶段结束用同一套 Playwright 脚本重拍 20 张截图，与旧版对比留档。

## 4. 验收标准（可勾选）

- [ ] 390px 下：无横向滚动条、无文字竖排、页签单行可滑动、表格可用（卡片化或可横滑）、日历可读
- [ ] 768px 下：侧栏为图标条，内容单列不溢出
- [ ] 所有页面左边缘 x 坐标一致（同一容器规则）
- [ ] 折叠组件有可见箭头 + 展开/收起文字 + 过渡动画
- [ ] 正文 ≥15px，所有可点区域 ≥40×40px
- [ ] 表格行高 48px，掌握度条在 0% 时仍可见（灰色轨道 + "0%" 文字）
- [ ] 全站图标同一套（无 emoji 混入功能区）
- [ ] 空状态不与表单混排，且都有主动作
- [ ] 同一功能的按钮在全站长相一致

## 5. 待你决策

1. **移动端优先级**：孩子主要用电脑还是平板/手机？如果主要用平板横屏（1024px），P0-1 可降级为 P1，能省 0.5 天。
2. **是否补插画**：空状态/登录页要不要做一组线性插画（我可以用 SVG 画，风格统一，约 0.5 天）？还是先纯图标？
3. **深色模式**：要不要做？（孩子们一般用浅色，但你在暗色 IDE 环境，可能偏好）
4. **词库第四类命名**：现在页签叫"同义替换"，你最初说的是"其他单词（手动上传）"并列四类。是否合并为 `必默 | 高频 | 固定搭配 | 同义替换 | 我的生词` 五项（当前就是这样）？还是按原始四类、把"同义替换"并入"固定搭配/其他"？
5. **是否接受 6.5 人天的排期**，或先只做 P0 三项（2 天）看效果？
