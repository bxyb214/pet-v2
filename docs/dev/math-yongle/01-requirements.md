# 数学 · 李永乐「一课通关」— 需求

> 功能编号：MT1–MT7（见 docs/04）。日期：2026-11-23。

## 1. 背景与目标

数学板块当前只有「敬请期待」占位页。用户已把李永乐「一课通关」三年级 13 个视频上传到
NAS（`/vol2/1000/media/felix/math/grade_3/`，共约 5.4 GB）。目标：在站内直接看这些课，
并且只有**完整看完**一节才算学完，让家长/孩子看到真实进度。

## 2. 用户故事

- **US-01**：作为学生，我希望在数学板块看到三年级的课程清单（按主题分组），以便按顺序学。
- **US-02**：作为学生，我希望视频能 1.0 / 1.25 / 1.5 倍速播放，以便按自己的节奏学。
- **US-03**：作为学生，我希望只有看完一整节才打勾，以便进度真实可信。
- **US-04**：作为学生，我希望在 iPad 上把视频投到电视（AirPlay），以便大屏观看。
- **US-05**：作为学生，我希望换设备登录后学习进度还在，以便继续学。
- **US-06**：作为学生，我希望没看完的课下次从上次位置继续，以便不用拖进度条。

## 3. 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| MT1 | 数学板块入口：侧栏「数学」→ 课程页；三级页签「课程 / 学习进度」 | P0 |
| MT2 | 课程清单：13 节，按主题分组（枚举法 / 专题讲座 / 加法原理和乘法原理 / 图形计数 / 长方形和正方形的面积），显示序号、标题、难度标签、状态 | P0 |
| MT3 | 播放器：播放/暂停、进度拖动、时间、全屏；服务端支持 HTTP Range（可任意拖动） | P0 |
| MT4 | 倍速：1.0 / 1.25 / 1.5 三档；记住上次选择（仅本地） | P0 |
| MT5 | 学习进度：**播放到结尾（ended）才算学完**；学完标记不可撤销（并集）；未学完的课记住已看秒数 | P0 |
| MT6 | iPad 投屏：Safari 显示「投屏」按钮（AirPlay 目标选择器）；支持 Remote Playback 的浏览器同样显示 | P0 |
| MT7 | 学习进度页：13 格进度墙（学完 / 学习中 / 未开始）+ 学习中清单（上次看到 mm:ss） | P1 |

### 判定口径

- **学完**：该课 `ended` 事件触发一次即记为学完（`progress.seen` 含 `done`），之后不会再变回未学完。
- **学习中**：未学完且已看秒数 > 0。
- **续播**：未学完且上次位置 > 10 秒、且距结尾 > 10 秒时，打开即从上次位置开始；学完的课从头播放。
- 允许拖动到结尾直接算学完（家庭场景不做防作弊，见 §4）。

## 4. 边界与非目标

- 只展示三年级 13 节；不做上传/删除/排序的管理界面（新增课程改 `data-src/math/` 后重新构建）。
- 不转码、不抽字幕、不提供下载；视频编码需浏览器原生可播（H.264/AAC MP4）。
- 视频由 nginx 静态直出，**不经后端 API、不做逐请求鉴权**（与现有听力音频一致，家庭局域网使用）。
- 不统计"总观看时长"这类无法从单条记录还原的指标；只展示完成数与上次位置。
- 不修改同步合并语义（红线）：复用 `progress` 的 `seen` 并集 + `idx` 取大。

## 5. 验收标准（Given / When / Then）

| 编号 | Given | When | Then |
|---|---|---|---|
| MT1-AC | 已登录用户 | 点侧栏「数学」 | 进入 `/math/lessons`，侧栏高亮数学，出现「课程 / 学习进度」页签 |
| MT2-AC | 13 节数据 | 打开课程页 | 按 5 个主题分组展示 13 节，序号 40–50（含 43.1/43.2），有难度标签与状态 |
| MT3-AC | 打开任意一节 | 点击播放并拖动进度条 | 视频从目标位置继续；播放/暂停、时间、全屏可用 |
| MT4-AC | 视频已加载 | 点 1.25x | `playbackRate=1.25`，按钮高亮；刷新后再看仍为 1.25x |
| MT5-AC-1 | 未学完的课 | 播放到结尾 | 出现「已学完」，课程页/进度页该课变绿色对勾 |
| MT5-AC-2 | 看到 3 分钟退出 | 重新打开该课 | 从约 3 分钟处继续播放 |
| MT5-AC-3 | 两台设备看过不同课 | 同步完成 | 两边的完成记录取并集，不互相覆盖 |
| MT6-AC | iPad Safari 打开视频页 | 点「投屏」 | 弹出 AirPlay 设备选择器 |
| MT7-AC | 完成 4 节、另 2 节看了一半 | 打开学习进度页 | 显示 4/13、13 格三态、2 条「上次看到 mm:ss」 |

## 6. 影响面

- 前端：新增 `core/math.ts`、`views/MathHome.vue`、`views/MathLesson.vue`、`views/MathProgress.vue`；
  路由 `router/index.ts`；`layouts/SiderNav.vue`；`stores/learning.ts` 增加视频进度动作。
- 数据：新增 `data-src/math/yongle_grade3.json` 与 `tools/build_math.js` → `frontend/public/data/math.json`。
- 部署：`deploy/docker-compose.yml` / `docker-compose.dev.yml` 给 nginx 增加只读媒体卷；
  `deploy/nginx.conf` 增加 `/media/math/` 静态映射。
- 后端：**无接口与表结构变更**；复用 `/sync` 的 `progress`。
- 运维：NAS 媒体目录需对容器用户（nginx uid 101）可读（见 docs/06）。
