# 词汇计划预览校验修复 — 需求

## 背景

创建词汇计划时只能点「预览」，预览后显示「切分校验未通过，请重试」，
「确认生成」按钮永远不出现，计划无法创建。

用户同时明确：**每天不需要严格平分，多一个少一个都可以**。

## 用户故事

- US-01：作为学习者，我选好天数、预览通过后能确认生成计划。
- US-02：作为学习者，每天的词量可以相差 1 个，但我希望每天都有词，不想看到空天。
- US-03：作为维护者，PET 与 KET 共用一个 `banks.json`，切分/校验必须只针对当前级别。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 修复预览校验误报：只校验当前级别参与切分的词库 | P0 |
| F-02 | 切分按总数平分到天，每天 `floor(N/天)` 或 +1 个，不产生空天 | P0 |
| F-03 | 修改天数后清空旧预览，避免「确认生成」沿用上一次天数 | P1 |
| F-04 | 词库未加载完成时禁用预览，避免用空词库生成空计划 | P1 |
| F-05 | 预览展示全部天数（不再只显示前 8 天） | P1 |

## 边界与非目标

- 不改变计划存储结构（仍只存 `plan.length` 与 `days_done`）。
- 不改变词库内容、不改数据构建链。
- 不要求每天严格相同；允许相差 1 个。
- 阅读计划（R9）切分逻辑不变。

## 验收标准

- Given PET 账号打开词汇计划，When 输入 30 天并点「预览」，Then 无校验错误，显示「确认生成」。
- Given KET 账号，When 同样操作，Then 只按 KET 五库切分，预览通过。
- Given 任意合法天数，When 预览，Then 每天词量最大值与最小值相差不超过 1，且没有 0 词的天。
- Given 预览后修改天数，When 再次点「确认生成」，Then 使用新天数而不是旧预览。
- Given 词库尚未加载，When 点「预览」，Then 按钮不可用。
- Given 计划 30 天，When 预览，Then 页面展示 30 张天卡片（不是只显示 8 张）。
