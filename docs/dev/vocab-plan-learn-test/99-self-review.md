## 2. 设计一致性

- 未新增后端表、API、同步字段；计划仍只同步 `length / days_done / plan_updated_at`。
- 题目不落库，种子确定性生成；计划重建（时间戳变化）自然换题。
- 会话键改为作用域：`plan:<用户>:<plan_updated_at>:<day>:<bank>` / `free:<用户>`，版本升到 2。
- 与设计偏差：补充了「最后一题已答未点看结果也算本库完成」、自由测验切计划时清理旧轮次、
  单库 >80 题隐藏逐题进度分段（避免超长计划渲染数千节点）。
- 附带修复：自由测验「错题优先」此前会把整库排进本轮，现仍受 10/20 题上限。
