# 词汇计划：学习 / 测试分库 + 按库测试 — 需求

> 依据：用户对 v1 的口述（截图未送达），以及 2026-11-23 的 4 项确认：
> ① 必默考「拼写 / 看词选义 / 看义选词」，高频、固定搭配、同义替换只考「看词选义 / 看义选词」；
> ② 计划里的「学习」采用翻卡浏览；③ 测试题用计划创建时间做种子确定性生成；
> ④ 当天四个词库的测试都完成才给这一天打勾。

## 背景

当前词汇计划把当天四库合并成一整轮测验，计划页只有一个「学习第 N 天」入口，
没有 v1 的「学习 / 测试」之分，也不能按四个词库分别学、分别测。
测试题型由 `bankMeta.dims` 逐词轮换，不是每个词都覆盖该库要求的题型；
题目选项每次进入随机重排，不符合「创建计划时生成」的预期。

## 用户故事

- US-01：作为学生，我在计划页能看到「学习」和「测试」两个入口，分别进入当天内容。
- US-02：作为学生，学习时可以按四个词库切换，用翻卡方式看当天单词、释义、例句并听发音。
- US-03：作为学生，测试时可以按四个词库切换，每个库独立记录进度，做完一个库再换下一个。
- US-04：作为学生，必默词的测试覆盖拼写、看词选义、看义选词三种题型；
  其他词库只考看词选义、看义选词，不考拼写。
- US-05：作为学生/家长，同一天反复进入测试，题目和选项保持一致（计划创建时就已确定）。
- US-06：作为学生，只有当天四个词库的测试都做完，计划才打勾；中途退出可继续。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 计划页提供「学习第 N 天」和「测试第 N 天」两个入口；N 仍为第一个未完成天 | P0 |
| F-02 | 学习页按当前级别词库（PET 四库 / KET 五库）切换，翻卡看当天单词，支持发音 | P0 |
| F-03 | 测试页顶部有词库导航，显示每库已答/总数与完成状态，可随时切换 | P0 |
| F-04 | 每个词按该库测试题型出题：必默三型全考；高频/固搭/同义只考看词选义 + 看义选词 | P0 |
| F-05 | 计划测试题以 `plan_updated_at + day + bank` 为种子确定性生成；同计划同天同库稳定 | P0 |
| F-06 | 每个词库的测试进度独立保存/续做；四库全部完成才 `markPlanDayDone` | P0 |
| F-07 | 学习页可直接跳到当前词库的测试 | P1 |
| F-08 | 测试错题记账按该库实际测试维度重欠；答对划单维，完成全部维度后移出错题本 | P0 |

## 边界与非目标

- 不新增后端表、API、Alembic 迁移；计划仍只同步 `length / days_done / plan_updated_at`。
- 不把题目写入同步数据；题目由种子确定性生成，跨设备同计划同天同库一致。
- 每库测试会话仍只存 localStorage，不跨设备续做。
- 自由测验（从词库页「学习本词库」进入）保持原有 10/20 题与题型规则，本次只复用新的会话键。
- 学习页只浏览，不计时、不打勾、不写掌握/错题。
- 不改变计划切分算法（`splitPlan`）与计划合并语义（红线）。

## 验收标准

- Given 有计划，When 打开计划页，Then 同时看到「学习第 N 天」「测试第 N 天」。
- Given 进入学习页，Then 默认显示当天第一个有词的词库，可切换四库；卡片可翻面、发音。
- Given 必默库当天有 10 个词，When 进入必默测试，Then 共 30 题（每词拼写/看词选义/看义选词各 1）。
- Given 高频库当天有 10 个词，Then 共 20 题，不含拼写。
- Given 同一计划、同一天、同一库，When 退出后重新进入，Then 题目顺序与选项一致。
- Given 只做完必默库测试，Then 当天不打勾；四库测试全部完成，Then 当天打勾一次。
- Given 必默做完、高频做一半时刷新，Then 回到测试页时必默显示已完成，高频从第一道未答题继续。
- Given 计划删除/改天数/重建，Then 旧会话不再恢复，按新计划重新生成。
- Given 计划测试答错，Then 错题本按该库测试维度记录；答对逐维划掉，全部划掉后移出。

## 影响面

- 前端：`core/quiz.ts`（确定性生成、按词出多题）、`core/quizSession.ts`（按作用域分键）、

  `views/QuizPage.vue`（分库测试）、路由与测试。
- 后端：无。
- 数据文件：不改 `frontend/public/data/banks.json`；测试题型规则在代码层按词库应用。
