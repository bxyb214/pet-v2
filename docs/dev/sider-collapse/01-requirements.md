# 左侧栏按宽度折叠 — 需求

> 日期：2026-11-24；关联 [02 设计](02-design.md)、[99 自省](99-self-review.md)。

## 1. 背景与目标

桌面端左侧栏固定 240px，宽屏够用，但在 1024–1279px 的笔记本/分屏窗口里
（尤其口语页右侧还有数字人面板）会明显挤压学习内容；「平时学习」时希望把空间让给内容。

目标：

1. 侧栏可按窗口宽度**默认**展开或收起；桌面提供手动切换。
2. 收起后保留图标条，仍能切学科/板块，不强迫用手机抽屉。
3. 不改变手机（<768）现有的抽屉导航与页面内容宽度规则。

## 2. 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| SC-1 | ≥1280：默认展开（240px）；<1280 且 ≥1024：默认收起（74px 图标条） | P0 |
| SC-2 | 桌面窗口提供「收起 / 展开」按钮，点击即时切换，`aria-expanded` / `aria-label` 正确 | P0 |
| SC-3 | 手动切换后记住选择（刷新/重开仍生效）；未手动切换时随窗口宽度自动变化 | P0 |
| SC-4 | 768–1023 固定为图标条（不显示切换按钮）；<768 仍为抽屉 + 顶栏菜单 | P1 |
| SC-5 | 收起态隐藏文字/页脚，只留图标，悬停有 `title` 提示 | P1 |

## 3. 验收标准（Given / When / Then）

| 编号 | Given | When | Then |
|---|---|---|---|
| SC-AC1 | 未设置过偏好 | 打开 1440px / 1280px 窗口 | 侧栏 240px、文字可见 |
| SC-AC2 | 未设置过偏好 | 打开 1279px / 1200px 窗口 | 侧栏 74px、只剩图标，按钮标签「展开侧栏」 |
| SC-AC3 | 1200px 默认收起 | 点「展开」并刷新 | 仍为 240px（`localStorage.pet_sider = open`） |
| SC-AC4 | 已手动收起 | 把窗口放大到 1440px | 仍保持收起（手动优先） |
| SC-AC5 | 1024px 以下平板 | 查看侧栏 | 74px 图标条，无切换按钮 |
| SC-AC6 | 手机 390px | 打开页面 | 侧栏隐藏，顶栏汉堡按钮打开抽屉 |

## 4. 非目标

- 不做按具体页面（如视频课/答题页）自动折叠；默认只由宽度决定，避免学习中途布局跳动。
- 不改内容区 960 / 720 的宽度规则；不新增后端接口与表结构。
- 不改手机抽屉的宽度与交互。
