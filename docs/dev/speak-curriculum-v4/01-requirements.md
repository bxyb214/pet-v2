# 口语跟读 / 造句 / 题库重组 v4 — 需求

## 背景

当前口语数据把 Part1 的 17 个分类、Part2 的 89 个图片场景、Part3–4 的 55 个讨论话题
原样铺开成 **161 个场景**，跟读句来自 85 题问答（大量模板/残句），造句只按 11 组句型
自由发挥。结果是：场景过多、跟读句不够完整、跟读/造句/题库三者对不上。

## 目标

一个 **45 个场景**的统一语料体系：每个场景同时提供跟读句、造句题、对话开场，
三者主题一致，跟读句全部为 PET 优秀水平（B1+）的完整句子。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 场景由 161 整合为 45 个（Part1 14 / Part2 16 / Part3 15） | P0 |
| F-02 | 每个场景 3 条跟读句：完整句、B1+、中文翻译、朗读提示 | P0 |
| F-03 | 每个场景 2 道造句题：中文提示 + 标准英文答案 + 句型标签 | P0 |
| F-04 | 跟读 / 造句 / 对话共用同一场景 id，题库页与计划页只展示这 45 个 | P0 |
| F-05 | 造句页展示中文提示；用户**开口说英文**；可查看标准答案 | P0 |
| F-06 | 造句提交后调用 AI 给修改建议（保留原意，给出 B1 优化句） | P0 |
| F-07 | 无法使用麦克风/语音服务时，可键盘输入完成同一流程 | P1 |
| F-08 | 数据构建脚本可复现，并校验数量、字段完整性 | P0 |

## 内容约束

- 跟读句必须是能独立成立的完整句（有主语和谓语），10–20 词，含连接词/从句等 B1+ 特征。
- 造句题的中文提示必须是「要表达的意思」，不是语法填空；标准答案与提示一一对应。
- 场景标题与内容对应现行 PET 口语三部分：Part1 访谈、Part2 图片描述、Part3–4 讨论。
- 内容来源可追溯：`data-src/speak/` 教辅 + 真题目录；不把未核对的真题答案当作教材原文。

## 非目标

- 不改评分标准、记忆曲线、计划打卡与用时统计语义。
- 不新增第三方依赖；语音输入复用现有 Qwen Realtime 通道。
- 不处理 Part2 图片裁切（图片仍为文字场景）。

## 验收标准

- `speak.json` 中 `scenes.length === 45`，每个场景 `shadow.length === 3`、`make.length === 2`。
- 跟读页的包与场景一一对应，任选场景都能加载到 3 条完整句。
- 造句页：显示中文 → 说/输入英文 → 显示标准答案 → 显示 AI 点评与优化句。
- `vitest`、`pytest`、`vue-tsc`、`vite build` 通过。
