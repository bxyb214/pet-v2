# 口语 15+15 与手动计划 — 需求

## 背景

用户提出的三个问题：

1. 口语计划要像词汇计划一样可以手动创建；已有计划时只显示删除，没有计划时才显示创建。
2. 每天 5 分钟跟读 + 10 分钟造句 + 15 分钟自由对话（10 分钟对话 + 5 分钟复盘）；
   对话中的回答由 AI 优化后跟读，最好穿插在对话里；取消「复盘」二级页面。
3. 口语权限：普通用户默认无权限，进入时有 AI 费用提示；管理员可以开/关权限。
4. 161 个 PET 真题场景作为独立题库，不混在首页；每日计划要列出当天的场景。

排查中另发现两个阻塞问题：

- 前端口语接口大多写成 `/api/v1/english/speak/...`，后端实际是 `/api/v1/speak/...`，
  days / log / boot / review / tts 等请求全部 404。
- `speak.json` 的 `plan.days[].shadow/scene` 是旧编号（`sh001` / `c101`），与 v3 的
  `shadow[].id`（`tp85-xx`）和 `scenes[].id`（`sc1-x`）对不上，按计划日取内容会为空。

## 用户故事

- US-01 作为学生，我能像创建词汇计划一样输入天数生成口语计划；已有计划时只能删除，删除后可重新创建。
- US-02 作为学生，我每天看到「跟读 5 分钟」「造句 10 分钟」「对话 15 分钟（10+5）」的节奏提示，但不会被强制中断。
- US-03 作为学生，我每说完一句，AI 就给出更好的 PET 说法，我可以当场听示范并跟读。
- US-04 作为学生，对话结束后在同一个页面完成 5 分钟复盘，不需要再跳到另一个页面。
- US-05 作为普通用户，没有口语权限时看到费用提示；管理员开通后立即可用，关闭后立即被拒。
- US-06 作为学生，161 个真题场景放在独立题库里，我可以在计划里看到当天场景，也可以单独练。
- US-07 作为学生，计划卡不会同时出现「创建/修改/删除」三个动作：有且仅有删除，或仅有创建。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 修复全部口语 API 路径：`/english/speak/*` → `/speak/*` | P0 |
| F-02 | 计划手动创建：1–90 天，按比例切分 packs/scenes；**有则只显示删除，无则只显示创建** | P0 |
| F-03 | 计划日历按用户天数显示，完成状态按合并后的原始天计算 | P0 |
| F-04 | 跟读页：显示 5 分钟计时/剩余，到点提示不强制 | P0 |
| F-05 | 造句页：显示 10 分钟计时/剩余，到点提示不强制 | P0 |
| F-06 | 对话页：15 分钟目标（10 分钟对话 + 5 分钟复盘），均只提示不强制 | P0 |
| F-07 | 每轮孩子回答 → `/speak/improve` → 对话内展示优化句 + 听示范 + 跟读评分 | P0 |
| F-08 | 对话结束 → 优化句落库 → 页内 5 分钟复盘 → 记忆曲线评分 | P0 |
| F-09 | 删除独立「复盘」页签/路由/页面，旧链接回口语首页 | P0 |
| F-10 | 管理员可开/关任意账号口语权限，也可关闭自己的权限 | P0 |
| F-11 | 161 场景独立题库页；计划日列出当天场景，可直接进入 | P0 |

## 非目标

- 不改同步合并语义（口语计划走独立表，不进入 SyncData.plan）。
- 不改 SOE / Realtime 协议和计费规则。
- 不重录或转换音频。

## 验收标准

1. Given 无计划，Then 只出现「创建计划」；输入 30 天并确认后，日历 30 格且只出现「删除计划」；删除后回到只有「创建计划」。
2. Given 30 天计划，When 打开第 1 天跟读，Then 显示「第 1–3 天」及非空句子。
3. Given 跟读页，Then 显示 5:00 目标；超过 5 分钟只变色提示，不自动退出。
4. Given 造句页，Then 显示 10:00 目标；超过 10 分钟只变色提示。
5. Given 对话页，Then 显示 15 分钟目标（10 分钟对话 + 5 分钟复盘）；聊到 10 分钟提示可进入复盘，不自动结束。
6. Given AI Key 可用，When 孩子说完一句，Then 对话气泡下出现优化句、听示范与跟读按钮。
7. Given 结束对话，Then 同页展开 5 分钟复盘；页签与路由中不再有独立「复盘」。
8. Given 普通用户无 speak，When 打开口语，Then 显示「请联系管理员」；管理员开通后可进入，关闭后接口 403。
9. Given 管理员账号，Then 管理页的口语开关可点击，关闭后自己也无法调用口语接口，但管理后台仍可访问。
10. Given 场景题库页，Then 显示 161 个场景并按 Part 可筛选；计划页列出当天场景并可点击进入对话。
