# 口语 Part 2 — 需求（计划进度 / 时长 / 题库入口 / 返回按钮）

## 背景

第一版上线后用户反馈：

1. **计划进度错误**：创建计划后点一天就显示完成，而不是完成当天的任务。
   根因是旧的 90 天打卡记录被新计划直接复用，且完成条件只看了跟读+对话。
2. **计时不应是页面停留时间**：当前倒计时在前端按秒累加，刷新就丢，也不代表孩子真的开口。
3. **场景题库入口重复**：首页已有「场景题库」卡片，但二级页签里也已有题库，卡片可删。
4. **返回按钮太小**：iPad 上文字链接不好点，需要醒目、易点。

## 用户故事

- US-01 作为学生，创建新计划后所有天都是未完成；完成一天必须做完当天的跟读、造句、对话。
- US-02 作为学生，计时只累计我真正开口的时间，刷新页面后今天的累计还在。
- US-03 作为学生，我在首页只看到三个每日入口；场景题库从页签进入即可。
- US-04 作为学生/家长，在 iPad 上能一眼看到并轻松点到返回按钮。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 新建/修改计划时重置该用户的打卡记录；完成条件改为跟读+造句+对话三项 | P0 |
| F-02 | 造句练习完成后写入 `make_done` 打卡 | P0 |
| F-03 | 服务端按天累计练习秒数（shadow / make / talk），刷新不丢 | P0 |
| F-04 | 跟读/对话计时改为「真正开口」秒数（麦克风能量检测）；造句按页面可见练习时间 | P0 |
| F-05 | 首页删除「场景题库」卡片，保留「题库」页签与计划里的当天场景 | P1 |
| F-06 | 口语子页统一使用大号返回按钮（≥48px，iPad ≥54px） | P1 |

## 非目标

- 不改变 SOE / Realtime 协议与计费规则。
- 不删除历史 `speak_logs`；只重置打卡进度。
- 不把造句改成语音输入（本轮仍为文字造句）。

## 验收标准

1. Given 有旧打卡记录，When 创建 30 天计划，Then 日历显示 0/30，第 1 天未完成。
2. Given 30 天计划，When 点第 1 天进入跟读再返回，Then 第 1 天仍未完成。
3. Given 造句页，When 提交一次 AI 检查，Then 当天 `make_done=true`。
4. Given 今天已开口 2 分钟，When 刷新跟读页，Then 计时仍显示 2:00。
5. Given 首页，Then 只有跟读/造句/对话三个入口，无「场景题库」卡片。
6. Given iPad 宽度，Then 返回按钮高度 ≥54px 且可点击区域明显。
