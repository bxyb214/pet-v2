# 词汇计划：删除不复活 + 创建即生成题目 — 需求

## 背景

1. **Bug**：单词计划删除后，当前页面看似已删除，但刷新（或换设备）后计划又出现。
   根因是同步合并里 `length = 客户端 length || 服务端 length`，删除写入 0 会被服务端旧计划并回来。
2. **体验**：创建计划只生成「天数」，点「去学习」仍要手动选题库、题量，才会生成具体题目。
   用户希望创建计划时就把**必默 / 高频 / 固定搭配 / 同义替换**每天的题型生成好，学习时直接开始。

## 用户故事

- US-01：我删除单词计划后，刷新页面它不应该再回来。
- US-02：我创建 30 天计划时，系统已经按天生成好四个词库的题目和题型。
- US-03：我点「学习第 N 天」就直接答题，不再选题库/题量。
- US-04：当天整轮做完后，计划对应天自动打勾；中途退出不打卡。
- US-05：删除词汇计划不应误删阅读计划。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 删除词汇计划后同步不会复活；刷新仍为空 | P0 |
| F-02 | 删除词汇计划只清词汇字段，阅读计划保留 | P0 |
| F-03 | 创建计划时按天生成四库题目（题型按词库 dims：看义选词/看词选义/拼写） | P0 |
| F-04 | 计划页显示「已生成 M 道题」与「学习第 N 天」；N = 第一个未完成天 | P0 |
| F-05 | 学习页自动按计划日组题并开始，不再显示题库/题量设置 | P0 |
| F-06 | 整轮答完才 `markPlanDayDone`；结果页可再练同一天 | P0 |
| F-07 | 同义替换库中英混排（`cn=null`）在加载时拆分，保证选择题可用 | P0 |
| F-08 | 新用户 rev=0 时先 pull 再 push，避免首次同步 422 | P1 |

## 边界与非目标

- 不改四库切分算法（仍按总数平分、多一个少一个、不重不漏）。
- 不把题目 JSON 存进数据库：题目由「词库 + 计划天数 + 第几天」确定性生成，跨设备一致。
- 从词库页「学习本词库」进入仍保留自由测验（可选库/题量），不强制计划模式。
- 不改错题本/掌握度记账规则。

## 验收标准

- Given 已有词汇计划，When 删除并等同步后刷新，Then 显示「还没有词汇计划」，服务端 `plans.length=0`。
- Given 删除词汇计划前有阅读计划，Then 阅读计划仍保留。
- Given 创建 30 天 PET 计划，Then 页面显示共 1680 题，按钮为「学习第 1 天」。
- Given 点「学习第 1 天」，Then 直接进入答题，顶部显示「第 1 天 · 必默 x · 高频 y · 固搭 z · 同义 w · 共 T 题」，无设置卡片。
- Given 完成当天全部题目，Then 结果页出现，`days_done` 含该天。
- Given 同义替换词「a DVD you can keep 你可以拥有的 DVD」，Then 看义选词提示为中文、看词选义选项为中文，不再出现 `null` 或报错。
