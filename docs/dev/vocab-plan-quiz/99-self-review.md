## 遗留项

1. 计划题目由词库确定性生成，不保存快照；词库内容升级后同一天的题目内容会随之上新。
2. 题目时间戳用客户端 `Date.now()`，多设备时钟大幅偏差时，极端并发删除/重建可能判旧；常规使用无影响。
3. 一天可能 50+ 题，暂未做“分两段/中途保存”的断点；中途退出不打卡，下次可重新开始。
4. 同义替换的 `en` 文本仍然是一条英文短语 + 中文，拆分只保证答题可用，未重写词库源数据（源站只读）。
