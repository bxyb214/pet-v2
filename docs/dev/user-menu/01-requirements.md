# 顶栏用户菜单 — 需求

## 背景

右上角把用户名/DEV、设置、管理、退出平铺成一排，窄屏时挤占空间；
管理只对管理员可见，平铺也让权限差异显得零散。

## 用户故事

- US-01：作为用户，我点右上角头像/DEV，就能看到设置与退出。
- US-02：作为管理员，我还能在同一个菜单里进入管理后台。
- US-03：作为手机/平板用户，顶栏不再被一排按钮挤满。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 设置 / 管理 / 退出收进右上角下拉菜单 | P0 |
| F-02 | 触发区：普通环境显示头像 + 名称，开发环境显示 DEV；均带下拉箭头 | P0 |
| F-03 | 管理项仅管理员可见 | P0 |
| F-04 | 菜单顶部显示当前身份（开发环境 · DEV / 用户名，禁用态） | P1 |
| F-05 | 设置/管理走路由，退出清会话回登录；键盘与触屏可用 | P0 |

## 边界与非目标

- 不改登录/权限逻辑，不改 DEV 判定。
- 不新增二级页面或菜单项。
- 不在菜单里放学习板块导航（仍由侧栏负责）。

## 验收标准

- Given 开发环境，When 打开任意业务页，Then 右上角只有一个「DEV + 箭头」触发器，没有平铺的设置/管理/退出。
- Given 点触发器，Then 下拉显示「开发环境 · DEV / 设置 / 管理 / 退出」；管理仅管理员有。
- Given 点「设置」/「管理」，Then 进入对应页面。
- Given 点「退出」，Then 清除 token 并回 `/login`。
- Given 390px 手机，Then 菜单可点开，页面无横向滚动。
