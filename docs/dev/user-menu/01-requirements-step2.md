# 顶栏用户菜单 · 第二步需求（首字母折叠）

## 背景

下拉菜单上线后，触发器在开发环境只有 DEV、没有用户身份；窄屏时用户名整体隐藏，
希望能用首字母保留“这是谁”的信息，同时 DEV 标识不要被折掉。

## 用户故事

- US-01：作为用户，无论中英文名，折叠时都能看到自己的首字母。
- US-02：作为测试者，开发环境仍保留完整的 DEV 标识，同时能看出当前账号。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-06 | 触发器始终显示用户首字母头像（开发环境也显示） | P0 |
| F-07 | DEV 标识保持完整，不随窄屏折叠，且位于用户头像左侧、两者不重叠 | P0 |
| F-08 | 窄屏（≤767px）隐藏完整名称，只留首字母 + DEV/箭头 | P0 |
| F-09 | 中文取首字，英文取首字母并大写；兼容代理对，空名回退「学」 | P0 |
| F-10 | 触发器 `title` / `aria-label` 带完整用户名 | P1 |

## 边界与非目标

- 不改变下拉菜单项与权限逻辑。
- 开发环境仍不显示完整用户名（只显示首字母 + DEV）。
- 不改头像以外的视觉体系。

## 验收标准

- Given 开发环境 admin，Then 触发器为「DEV + A + 箭头」（DEV 在左），无完整用户名，两者间距清晰不重叠。
- Given 正式环境 admin，Then 触发器为「A + admin + 箭头」；手机为「A + 箭头」。
- Given 用户「团小牛」，Then 首字母为「团」；英文名 felix → F。
- Given 任意宽度，DEV 标识完整可见。
- Given 悬停/读屏，Then 能读到完整用户名。
