# 顶栏用户菜单 — 设计

## 1. 结构

```text
顶栏右侧
┌───────────────────────────────┐
│ (头像) 名字 ▾     或    DEV ▾ │  ← n-dropdown 触发器
└───────────────────────────────┘
            │ click
            ▼
   ┌──────────────────────┐
   │ 开发环境 · DEV        │  禁用态身份行
   ├──────────────────────┤
   │ ⚙ 设置                │
   │ 🛡 管理（仅 admin）    │
   ├──────────────────────┤
   │ ↪ 退出（红）           │
   └──────────────────────┘
```

## 2. 触发区

- Naive UI `n-dropdown` + `trigger="click"` + `placement="bottom-end"`，触发器是原生 `<button class="userbtn">`。
- 普通环境：圆形头像（用户名首字）+ 显示名（≤120px 省略）+ 下箭头。
- 开发环境：沿用 `devbadge`（DEV + 橙点），隐藏用户名与头像；仍带下箭头。
- 手机（≤767px）：隐藏名称，只留头像/DEV + 箭头；按钮约 97px 宽，不影响顶栏。

## 3. 菜单项

| key | 标签 | 条件 | 行为 |
|---|---|---|---|
| who | 开发环境 · DEV / 显示名 | 永远 | 禁用，只做身份提示 |
| divider | — | 永远 | |
| settings | 设置 | 永远 | `router.push('/settings')` |
| admin | 管理 | `auth.isAdmin` | `router.push('/admin')` |
| divider | — | 永远 | |
| logout | 退出 | 永远 | `auth.logout()`（清 token、断开同步）→ `/login` |

- 图标用 `@vicons/ionicons5` 线性图标，经 `h(NIcon)` 渲染，符合“线性 SVG、不用 emoji”的规范。
- 退出项用 `--c-danger` 文字色，但没有二次确认：退出不破坏数据。

## 4. 备选方案与取舍

| 方案 | 结论 |
|---|---|
| 保留平铺按钮，只缩小间距 | ❌ 手机仍拥挤，管理员差异仍散落 |
| 自绘 popover | ❌ 重复 Naive 已提供的下拉定位/键盘/点击外部关闭 |
| 菜单里加入侧栏导航 | ❌ 与侧栏职责重叠，菜单会过长 |
| **n-dropdown + 身份行 + 权限项（选定）** | ✅ 复用组件、窄屏友好、权限集中 |

## 5. 测试

- 类型检查、104 项单测、构建。
- 浏览器：管理员菜单四项；设置/管理路由；退出清 token 回登录；非管理员无「管理」；
  390px 手机可打开且无横向滚动；无控制台错误。
