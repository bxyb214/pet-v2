# 品牌改名与登录/注册文案调整 — 需求

## 背景

产品对外名称由「绿野英语」改为「火焰学习」；同时精简登录页，并在注册页
把获取注册码的途径指向小淏。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 登录页、注册页品牌面板与顶栏 Logo 显示「火焰学习」 | P0 |
| F-02 | 品牌图标由叶子改为火焰（顶栏 emoji、登录/注册页 SVG） | P1 |
| F-03 | 侧栏底部标语改为「火焰学习 · 每天进步一点点」 | P1 |
| F-04 | 浏览器标题改为「火焰学习 · PET 备考」 | P1 |
| F-05 | 登录页删除「用老师给你的用户名和密码」 | P0 |
| F-06 | 注册页删除「四步就好，之后用用户名登录」，改为提示找小淏要注册码 | P0 |

## 边界与非目标

- 不改主题色、Design Token、组件结构，不引入新依赖。
- 不改登录/注册接口、邀请码校验与同步逻辑。
- `docs/archive/` 旧文档与历史截图保持原样；设计语言「绿野成长」作为内部
  Token 名称不改，只改用户可见文案。

## 验收标准

- 登录页品牌名为「火焰学习」，登录标题下不再有说明句。
- 注册页（非首个账号）标题下显示「找小淏要注册码后注册」。
- 顶栏、侧栏、浏览器标题均不再出现「绿野英语」。
- `vitest`、`vue-tsc`、`vite build` 通过。

## 追加需求（第 2 轮）

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-07 | 注册页要点「邀请码由老师发放，一次性使用」→「邀请码找小淏要，一次性使用」 | P0 |
| F-08 | 浏览器标题去掉「PET 备考」，只保留「火焰学习」 | P0 |
| F-09 | 增加火焰 SVG favicon（16px 下可辨识） | P1 |

验收：页面 `<title>` 为「火焰学习」，`<link rel="icon">` 指向 `/favicon.svg`；
注册页第一条要点为「邀请码找小淏要，一次性使用」。
