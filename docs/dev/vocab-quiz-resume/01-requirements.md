# 单词测验断点续做 — 需求

## 背景

单词学习页（`/english/words/study`）的一轮题组只保存在组件内存里（`round / qIndex / results`）。
计划模式下一天可能有几十题，学到一半刷新页面，整轮题组和答题位置都会丢失，只能从第 1 题重来。
每题的掌握/错题记账本身已经写入本地并同步，丢的是**本轮走到哪、哪些题已答**。

## 用户故事

- US-01：作为学生，我学到第 20 题时刷新或误关页面，重新进入后能从第 21 题继续，而不是重做。
- US-02：作为学生，续做时已经答过的题不再重复出现，顶部进度和对错统计保持刷新前的样子。
- US-03：作为学生，计划或当天题组已经变化时，不要把我拉回一个过期的旧题组。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 每答完一题（提交答案后）把当前轮次写入本地；进入下一题时刷新保存时间 | P0 |
| F-02 | 重新进入学习页时恢复题组、选项、已答对错、当前正确数、错词列表，定位到第一道未答题 | P0 |
| F-03 | 计划模式校验：计划总天数、计划结构时间戳或 URL 指定天数与本轮不一致时不恢复，按当前计划重新开始 | P0 |
| F-04 | 自由测验模式同样可续做；从词库页带 `?bank=` 进入且与本轮词库不一致时不恢复 | P1 |
| F-05 | 整轮完成（点「看结果」或恢复时发现已全部答完）后删除本地轮次；轮次超过 7 天自动失效 | P1 |
| F-06 | 续做状态按登录用户隔离，换账号读不到别人的轮次 | P0 |

## 边界与非目标

- 不做跨设备续做：本轮题组不进入同步数据，不新增后端表、API、Alembic 迁移或同步字段。
- 不改变掌握/错题的记账规则与合并语义；每题仍按现有 `recordRight / recordWrong` 立即记账并同步。
- 不保存尚未提交的拼写草稿（输入框里没按提交的内容）。
- 不在续做时重新随机出题：恢复的就是刷新前那一轮（含选项顺序）。

## 验收标准

- Given 计划第 1 天共 56 题，已答完 20 题，When 刷新页面，Then 直接显示第 21 题，顶部 20 段已按对错着色，正确数保持。
- Given 第 5 题答错后刷新，Then 该题仍记为错题（原有行为），续做进度段显示为橙色，且不会再次要求答第 5 题。
- Given 计划已从 30 天改为 20 天（或删除后重建、或 URL 指定另一天），When 进入学习页，Then 不恢复旧轮次，按新计划开始。
- Given 已答完最后一题但还没点「看结果」时刷新，Then 进入结算页，计划当天正常打勾（只打一次）。
- Given 自由测验选了词库 A，刷新后仍续做 A；若从词库 B 的「学习」入口进入，则不恢复 A 的轮次，回到开局设置。
- Given 本地轮次保存超过 7 天或数据损坏，Then 静默丢弃并正常开局。
- Given 同一浏览器切换账号，Then 各自恢复各自的轮次。

## 影响面

- 前端：新增 `src/core/quizSession.ts`（纯逻辑）、修改 `src/views/QuizPage.vue`、新增核心单测。
- 后端：无改动（无表结构、API、同步 schema）。
- 数据：localStorage 新键 `pet_quiz_session::<用户名>`，与学习快照 `pet_sync_v2::<用户名>` 同构隔离。
