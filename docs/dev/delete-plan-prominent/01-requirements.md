# 「删除计划」按钮醒目化 — 需求

## 背景

词汇、阅读、口语三个计划页的「删除计划」使用的是 `quaternary` 文字按钮，灰红小字，
在长页面底部很容易被忽略，用户找不到删除入口。

## 用户故事

- US-01：作为用户，我能一眼看到「删除计划」在哪，而不是找一圈。
- US-02：作为用户，删除前仍能看到确认提示，避免误删。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 三个计划页的「删除计划」改为填充红色按钮 | P0 |
| F-02 | 加垃圾桶线性图标、加粗文字、≥42px 高、轻投影 | P0 |
| F-03 | 保留 `n-popconfirm` 二次确认与原有文案 | P0 |
| F-04 | 删除逻辑、打卡/进度保留规则不变 | P0 |

## 边界与非目标

- 不改删除接口与数据清理规则。
- 不把删除按钮移到页面顶栏或与「去学习」并排主位，避免误触。
- 仅统一“删除计划”这一处；其他危险操作不在本次范围。

## 验收标准

- Given 有计划的词汇/阅读/口语页，Then 删除按钮为红底白字、带垃圾桶图标、高度 ≥42px、有投影。
- Given 点击删除，Then 仍弹出原确认框；确认后才删除。
- Given 删除完成，Then 行为与之前一致（进度保留、可重新创建）。
