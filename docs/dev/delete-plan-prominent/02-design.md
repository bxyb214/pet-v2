# 「删除计划」按钮醒目化 — 设计

## 1. 视觉

```text
┌─────────────────────┐
│ 🗑  删除计划          │   ← 填充 --c-danger (#dc2626)，白字 700
└─────────────────────┘      高 42px，左右 18px，投影 0 6px 14px / 18%
```

- Naive UI：`<n-button type="error" strong class="del-plan">`，图标走 `#icon` 插槽（内联线性 SVG 垃圾桶）。
- 类 `.del-plan`：`min-height:42px; padding:0 18px; box-shadow`；hover 加深投影。
- 不使用 emoji（符合 §3 图标规范）；颜色由 Naive `error` 主题映射到 `--c-danger`。

## 2. 应用范围

| 页面 | 位置 |
|---|---|
| `views/PlanPage.vue`（词汇） | 计划进行中卡片底部 `.actions` |
| `views/ReadingPlanPage.vue`（阅读） | 计划进行中卡片底部 `.actions` |
| `views/SpeakHome.vue`（口语） | 计划卡片 `.plan-actions` |

三处保持同样的按钮结构；确认框文案沿用原页面，不合并删除语义。

## 3. 取舍

| 方案 | 结论 |
|---|---|
| 保持 quaternary 文字按钮 | ❌ 就是本次问题：太不显眼 |
| 红色描边 secondary | ❌ 仍偏轻，长页面里不够跳 |
| **填充红 + 图标 + 投影（选定）** | ✅ 一眼可见；仍在底部、需确认，不容易误触 |
| 移到页面顶部 | ❌ 危险操作不应占据主视线 |

## 4. 测试

- 类型检查、104 项单测、构建。
- 浏览器：口语计划页按钮可见、背景/文字/字重/高度/投影，点击仍出现确认框。
- 词汇/阅读页使用同一按钮结构与类，未单独造页面数据回归。
