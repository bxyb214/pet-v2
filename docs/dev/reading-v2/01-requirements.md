# reading-v2 迭代 — 需求（01）

来源：`docs/04-功能清单.md` R 组（R1–R4），基线为旧站阅读板块（`PET/js/reading-data.js`，207 句 / 12 套 test / 42 考点）。

## 功能需求

| # | 需求 | 说明 |
|---|---|---|
| R1 | 精读学习 | 按教材（Trainer 1/2）→ test → Part 走句学习：英文原句 + 中文 + 成分解析（parse）+ 考点讲解（gram）+ 精讲笔记（note）；提供「听整句」发音 |
| R2 | 阅读测验 | 三题型：**读懂句意**（选中文）、**选词填空**（挖 key）、**语法选择**（gq 四选一）；整套或单 Part；上限 24 题；打乱顺序 |
| R3 | 语法专项 | 按 42 考点筛 gq 题（每考点上限 20 题），按《10天掌握PET语法》10 天分组展示 |
| R4 | 朗读红线 | **答题前一律不给朗读**（blank 读出被挖词、meaning/grammar 直接给出答案）；反馈后给「听整句」 |
| R5 | 数据迁移 | 旧 `reading-data.js` → `frontend/public/data/reading.json`；迁移即校验（id 唯一、key∈en、gram 编号 1–42、gq 四选项、parse≥3） |
| R6 | 进度 | 完成 Part/整套测验 → 写入 learning store 的 progress（key=`read:<book>:<testNo>:<part>`），同步通道自动上行 |

## 边界（本迭代不做）

- 听力 / 口语板块（后续迭代）。
- 句子级音频（旧站无该数据，随听力迭代一起定方案）。
- 阅读成绩的历史报表。

## DoD

1. `reading.json` 生成且全部校验通过（0 问题）。
2. 前端三页面可用：首页（教材折叠 + 语法专项 chips）、学习页、测验页。
3. vitest 覆盖 quiz 构建不变量（选项 4 个且恰 1 正确、blank 挖空正确、上限、打乱后仍有全部题）。
4. 全量构建 + 测试通过；自省报告落盘。
