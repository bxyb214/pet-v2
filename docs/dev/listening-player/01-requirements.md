# 听力 Part 页改版 — 需求

## 背景

点击听力教材里的 Part 会被错误重定向到单词页（路由拼错，命中兜底
redirect）。现有 Part 页又包含作答、判分和错题记账，但实际使用方式是
**听音频、在纸质卷子上作答**，页面不需要这些功能。

## 用户故事

- US-01 作为学生，我点击任意 Part 后能进入对应的听力播放页，而不是被弹回单词页。
- US-02 作为学生，我可以播放/暂停音频、拖动进度，并按 0.8/0.9/1.0/1.1/1.2 变速。
- US-03 作为学生，我可以对照随音频高亮、自动滚动的字幕；也可以一键隐藏字幕。
- US-04 作为学生，页面上不出现题目、选项、作答框、正确答案或判分结果。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 修复 Part 跳转路径为 `/english/listening/part/:testNo/:part` | P0 |
| F-02 | 纯播放器：播放/暂停、进度条、时间显示 | P0 |
| F-03 | 五档倍速 0.8 / 0.9 / 1.0 / 1.1 / 1.2，默认 1.0 | P0 |
| F-04 | 字幕随音频高亮并自动滚动到当前句；可一键隐藏/显示 | P0 |
| F-05 | 移除题目、选项、配图、作答、判分、正确答案展示 | P0 |
| F-06 | 移除听力错题本入口与路由；旧链接回听力首页 | P1 |
| F-07 | 更新听力首页文案与完成标记（不再有判分完成态） | P1 |

## 非目标

- 不改听力数据 JSON 结构，不做音频转码。
- 不保留听力错题本；已有历史错题数据不主动删除。
- 不新增后端接口。

## 验收标准

1. Given 听力首页，When 点击任一 Part，Then 进入 `/english/listening/part/{testNo}/{part}` 并显示对应音频。
2. Given Part 页，When 点击 0.8×～1.2×，Then 音频以对应速率播放，按钮高亮当前档位。
3. Given 正在播放，Then 当前字幕行高亮且自动滚入可视区；点击字幕行可跳到该句。
4. Given 字幕开启，When 点击「字幕 开」，Then 字幕区域隐藏；再次点击恢复。
5. Given Part 页，Then 页面中不存在题目、选项、输入框、提交/判分、正确答案。
6. Given 旧地址 `/english/listening/review`，Then 重定向到 `/english/listening/home`。
