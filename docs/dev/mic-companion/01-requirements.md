# 麦克风数字人陪练 — 需求

## 背景

口语跟读、自由对话、句内跟读都需要占用麦克风，但界面上没有“正在采集”的明确反馈，
孩子/家长不知道麦克风是否已打开，也没有随手关闭的入口。

## 用户故事

- US-01：作为孩子，麦克风打开时能看到一个陪我说话的“数字人”，知道它正在听。
- US-02：作为家长，麦克风一直开着让我不放心，我要在数字人正下方一键关掉。
- US-03：作为测试者，开发环境（`PET_DEV_MODE=1`）也能看到数字人和关闭交互，但界面要标明是模拟语音。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 只要麦克风正在被采集（含开发环境模拟语音），显示数字人面板 | P0 |
| F-02 | 数字人约占屏幕 1/3：桌面右侧 33vw，平板/手机底部约 1/3 高 | P0 |
| F-03 | 数字人正下方固定「关闭麦克风」按钮，点击立即停止本次采集 | P0 |
| F-04 | 关闭后数字人消失，页面回到可重新开始的状态，并给出文字提示 | P0 |
| F-05 | 数字人占用期间给内容区留出空间，不遮挡页面主要操作 | P1 |
| F-06 | 开发环境标注「模拟语音中」，不谎称真实麦克风 | P1 |

## 边界与非目标

- 不改动 AI / SOE / WebRTC 的接口与评分逻辑。
- 不做虚拟形象口型同步、摄像头或视频。
- 不在没有麦克风的页面（词汇、阅读、听力等）显示数字人。
- 「关闭麦克风」结束当前语音练习，不是静音后继续会话；关闭后需重新开始。

## 验收标准

- Given 进入自由对话并点「开始对话」，When 麦克风（或模拟语音）开始采集，Then 右侧出现数字人，宽度约屏宽 1/3。
- Given 数字人显示中，When 点其下方「关闭麦克风」，Then 数字人消失、麦克风轨道停止、状态提示可重新开始。
- Given 跟读页通过 AI 或腾讯 SOE 开始练习，Then 同样出现数字人；关闭后回到开始按钮。
- Given 对话中内嵌「跟读这句」启动评分，Then 数字人保持显示；关闭后该卡片回到未评分状态。
- Given 视口 1280/768/390，Then 桌面为右侧面板，平板与手机为底部约 1/3 屏面板，按钮在数字人下方。
- Given 开发环境，Then 状态胶囊显示「模拟语音中」，提示文案说明未调用真实麦克风。
