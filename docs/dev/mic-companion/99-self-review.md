## 遗留项

1. 「关闭麦克风」会结束本次 Realtime/SOE 会话，不支持静音后原地继续；重新开始即可。
2. 真实 `getUserMedia` + Qwen/SOE 路径因测试环境无 Key 未做浏览器回归，仅由同一套登记/释放逻辑覆盖；
   正式环境灰度时需复核一次权限拒绝、拔耳机切换设备两种场景。
3. 数字人为 SVG 静态形象，未做口型同步；后续如需更拟人可替换为序列帧/Live2D，接入点不变。
