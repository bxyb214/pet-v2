# 单词「学习」页签随机学习 + 词库掌握度比例 — 需求

## 背景

「学习」页签此前在有词汇计划时会自动进入计划测试，用户无法单独随机练词；
开局也不能选择考核方式。词库页虽有单词语义上的掌握度，但没有词库整体的
「已掌握 / 学习中 / 未学习」比例，家长/学生看不到整体进度。

## 用户故事

- US-01：作为学生，点「学习」页签时进入随机学习，而不是被计划牵着走。
- US-02：作为学生，我可以自己选词库、题量和考核方式（单词填空 / 看词选义 / 看义选词）。
- US-03：作为学生，做完一轮后，答对/答错立即更新单词掌握度与错题本。
- US-04：作为学生/家长，我在词库页能看到当前词库的已掌握、学习中、未学习比例和数量。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 只有 URL 带 `?day=` 才进入计划测试；「学习」页签/无 day 进入随机学习 | P0 |
| F-02 | 随机学习可选题库、10/20 题、错题优先，以及至少一种考核方式 | P0 |
| F-03 | 考核方式按词库允许维度展示：PET 三型；KET 两型（不考单词填空） | P0 |
| F-04 | 随机抽词、按所选维度随机出题；题量严格不超过 10/20 | P0 |
| F-05 | 每题作答后立即更新 mastery / mistakes（现有记账规则不变） | P0 |
| F-06 | 词库页显示当前词库「已掌握 / 学习中 / 未学习」的百分比与数量，并配堆叠条 | P0 |
| F-07 | 单词行掌握度按该词库必考维度计算（必默三维、其他 PET 库两维、KET 两维） | P1 |
| F-08 | 「已掌握」= 无错题欠账且覆盖该词库全部必考维度；有部分掌握或错题欠账 = 学习中；其余 = 未学习 | P0 |

## 边界与非目标

- 不改变掌握/错题的合并与记账语义（答错全维度重欠、答对划单维、空则移出）。
- 不跨设备续做随机学习会话（仍只存本地，7 天有效）。
- 不新增后端表/API/同步字段。
- 不改变计划页的「学习（翻卡）/ 测试（分库）」流程；计划测试仍通过 `?day=` 进入。
- 自定义生词暂不纳入词库掌握度比例。

## 验收标准

- Given 已有计划，When 进入 `/english/words/study`（无 `?day=`），Then 显示「随机学习」设置，而不是计划测试。
- Given 选择必默库、只勾「单词填空」、开始，Then 本轮 10 题全部是单词填空题。
- Given KET 词库，Then 考核方式只显示「看词选义 / 看义选词」。
- Given 一种考核方式都不选，Then 「开始学习」不可用。
- Given 答对某词的一个维度，Then 该词掌握度增加；答错，Then 进入错题本并按该库测试维度记账。
- Given 打开词库页，Then 当前词库显示三类比例、数量与颜色条；单词行状态与比例随作答更新。
- Given 词库页切换到高频库，Then 比例按高频库自己的词和必考维度重新计算。

## 影响面

- 前端：`core/quiz.ts`（标签/随机取词）、新增 `core/mastery.ts`、`views/QuizPage.vue`（模式判断 + 考核方式）、
  `views/BrowsePage.vue`（掌握度比例）、测试。
- 后端：无。
- 数据：无 schema 变化；沿用现有 mastery / mistakes 同步数据。
