## 3. 掌握度口径（关键决策）

- **required = 该词库在计划测试中要求掌握的维度**：
  - 必默：单词填空 + 看词选义 + 看义选词（3）；
  - 高频 / 固定搭配 / 同义替换：看词选义 + 看义选词（2）；
  - KET：`bankMeta.dims`（2）。
- 这样计划测试完成后，非必默库也能显示「已掌握」，不会出现「学完整个计划但掌握率仍为 0」。
- 随机学习里额外勾选单词填空会写入 `mastered_dims`（并参与错题划维），但不改变 required 口径。
- 百分比保留一位小数；未学习取剩余值，三类合计 100。
- 「学习中」包含错题欠账；单词行仍区分「复习中」标签。
