# 单词「学习」页签随机学习 + 词库掌握度比例 — 设计

## 1. 模式判断

```text
/english/words/study                  → 随机学习（可选题库/题量/考核方式）
/english/words/study?bank=bimo        → 随机学习，默认选中 bimo
/english/words/study?day=1            → 计划测试（按天、四库导航）
/english/words/study?day=1&bank=bimo  → 计划测试，默认选中 bimo
```

`planMode = planLength > 0 && route.query.day != null`。计划页的「测试第 N 天」与学习页的
「去测试本库」都带 `?day=`，因此计划流程不受影响；侧栏「学习」页签回到随机学习。

## 2. 随机学习设置（`QuizPage.vue`）

- 词库：当前级别的词库胶囊（PET 四库 / KET 五库）。
- 考核方式：`spell / w2m / m2w` 复选，按 `bankMeta[bank].dims` 约束：
  - PET：单词填空、看词选义、看义选词；
  - KET：看词选义、看义选词（沿用旧站不考拼写）。
- 题量：10 / 20；错题优先；至少选一种考核方式，否则开始按钮禁用。
- 生成：`makeRound(bank, count, selectedDims, picked)`：
  - `picked`（错题优先）只决定顺序，仍严格截取 `count`；
  - 每个词从所选维度中随机抽一种，题干/选项与现有规则一致。
- 每答一题立即 `recordRight / recordWrong / recordMastery`，掌握度与词库页比例实时更新。
- 会话仍写 `pet_quiz_session::free:<用户名>`，刷新后从第一道未答题续做。

维度顺序固定为「单词填空 → 看词选义 → 看义选词」，标签由 `core/quiz.ts` 的 `DIM_LABEL` 提供。

## 3. 掌握度口径（新增 `core/mastery.ts`）

```text
required = 计划测试的题型维度（必默：单词填空+看词选义+看义选词；
           高频/固搭/同义：看词选义+看义选词；KET：两型）

已掌握   无错题欠账，且 mastered_dims 覆盖 required 的全部维度
学习中   有任意已掌握维度，或错题本仍有欠账（dims 非空）
未学习   既无掌握维度，也无错题欠账
```

- 按词库逐词统计，再汇总为数量与百分比。
- 百分比保留一位小数；未学习 = 100 - 已掌握 - 学习中，保证合计 100。
- 单词行进度 `masteryPct` = 已掌握维度数 / required 长度。
- 随机学习里额外练的单词填空也会写入 mastery，但不改变该库的 required 口径。
- 自定义生词不参与教材词库统计。

## 4. 词库页展示（`BrowsePage.vue`）

- 分类胶囊下方新增「本词库掌握度」卡片：
  - 三段堆叠条：绿=已掌握、暖橙=学习中、灰=未学习；
  - 图例显示百分比与数量（`已掌握 45.2% 320`）。
- 顶部统计卡「已掌握」改为显示全部教材词库的已掌握数量 + 百分比标签。
- 单词行：
  - 掌握度进度条按该词库 required 维度计算；
  - 状态：已掌握 / 复习中（错题欠账）/ 学习中 / 未学。
- 换词库或作答后由 Pinia 数据驱动实时重算。

## 5. 备选方案

| 方案 | 结论 |
|---|---|
| 学习页签继续自动进入计划测试 | ❌ 与「学习=随机学习」冲突，且无法选考核方式 |
| 只允许选一种考核方式 | ❌ 用户明确要自己选，多种随机更灵活 |
| 掌握度按全局三维统计 | ❌ KET 不考单词填空，词库应各自按 required 维度计算 |
| 掌握度按错误率/连续答对计算 | ❌ 现有 mastery 是维度并集，沿用并集口径改动最小、可跨端合并 |
| 掌握度比例放到后端统计 | ❌ 数据都在本地/同步快照中，前端纯函数即可，无 API 成本 |

## 6. 风险

| 风险 | 缓解 |
|---|---|
| 非必默库在计划测试中只考两型，可能长期停在「学习中」 | 随机学习可勾选单词填空补齐；比例仍按词库 required 口径展示 |
| 只选一种考核方式时，答错仍按全维度重欠 | 保留红线；后续可在任一轮补齐其他维度 |
| 比例四舍五入不合计 100 | 未学习取剩余值，保留一位小数 |
| 词库很大时统计性能 | 纯数组一次遍历，712/856 词量级无压力 |
| 用户取消全部考核方式 | 开始按钮禁用并提示「至少选一种」 |
