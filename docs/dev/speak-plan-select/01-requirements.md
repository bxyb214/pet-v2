# 口语计划选日与入口重排 — 需求

## 背景

口语计划页的日历数字看起来不可点击：原来是 `div`，点击会直接跳去当天跟读，
既没有选中反馈，也不能用键盘操作。同时「今日开口」和 5/10/15 三个入口排在日历下方，
每天最常用的操作被压在 30 格日历后面。

## 用户故事

- US-01：作为孩子，点日历上的某一天，能清楚看到选中了哪天，再用上方入口去练。
- US-02：作为孩子，选好一天后连做跟读/造句/对话，返回计划页时选中日还在。
- US-03：作为孩子，我想马上开始今天的练习，不想先划过整张日历。
- US-04：作为键盘/触屏用户，日历格可以直接点击并有明确的焦点/按下状态。

## 功能点

| 编号 | 功能 | 优先级 |
|---|---|---|
| F-01 | 把「今日开口」和 5/10/15 三个入口移到日历上方 | P0 |
| F-02 | 日历格改为按钮：点击选中该天，有选中描边与 `aria-pressed` | P0 |
| F-03 | 三个入口作用于选中的那一天，不再固定今天 | P0 |
| F-04 | 选中日的场景列表、日期范围文案跟随切换 | P1 |
| F-05 | 选中日按用户存 `sessionStorage`，去练习再返回仍保留；可一键「回到今天」 | P1 |
| F-06 | 删除/重建计划后清空选中日；计划变短时自动失效 | P1 |

## 边界与非目标

- 不改计划切分算法、打卡规则、服务端接口。
- 选日只是切换练习目标，不自动进入练习，也不改完成状态。
- 「今日开口」仍统计今天，不随选中日变化。

## 验收标准

- Given 有 30 天计划，When 打开口语计划页，Then 顶部依次是今日开口、三个入口、日历。
- Given 点击第 5 天，Then 页面不跳转；第 5 天出现选中描边，入口标题变为「已选 · 第 5 天」，场景与日期范围变为第 5 天。
- Given 已选第 5 天，When 点「跟读纠音」，Then 进入 `shadow?day=5`；返回计划页仍是第 5 天。
- Given 已选第 5 天，When 点「回到今天」，Then 恢复为今天对应的计划日与场景。
- Given 键盘聚焦某天并按 Enter，Then 与点击一致。
- Given 删除计划，Then 选中日清空，页面回到创建状态。
