# 词汇计划切分对齐 v1 + felix 计划迁移核对 — 需求

## 背景

昨天迁移后，felix 的词汇计划第 24 天数据与 v1 不一致：

| 版本 | 第 24 天学习单词 | 第 24 天题目 |
|---|---|---|
| v1 | 57 个词条 | 72 题 |
| v2（当前） | 49 个词条 | 49 题 |

原因：v2 后来把切分改成「全部词库合起来按总数平分到天」，而 v1 是
**每种词库各自平均分到各天**。需要：

1. 把 v2 切分改回 v1 语义：必默、高频、固定搭配、同义替换各自平均分到每天；
2. 核对 felix 迁移后的计划（长度、已完成天、各库每天词数）；
3. 弄清明细题量 72 vs 49 的生成规则，完成迁移/修正。

## 边界与非目标

- 不改计划合并语义（仍同步 `length / days_done / plan_updated_at`）。
- 不修改 v1 线上代码或数据；v1 只读。
- 敏感信息（DB 口令、Key）只从服务器环境读取，不入 git、不写进文档。
- 本次先改代码切分；远程核对与迁移需 SSH 权限。

## 验收标准

- Given PET 四库 712/414/254/300 和 30 天计划，Then 第 24 天为 24/14/9/10，共 57 词。
- Given 任意天数 N，Then 每个词库每天条数最多差 1；库内顺序不变、不重不漏。
- Given 180 天 PET 计划，Then 每天四库都至少 1 个词（最小库 254 > 180）。
- Given 打开计划预览，Then 显示「每种词库各自平均分到各天」，不再宣称每天总数只差 1。
- Given 核对 felix 计划，Then 能看到 v2 的 length/days_done 与第 24 天各库词数，并说明与 v1 的差异。
- Given v1 第 24 天 72 题，Then 能定位其题目生成规则并给出 v2 对齐方案。
