一句话结论

结构骨架（左侧学科导航 + 三级页签）方向是对的，但最后一公里没做完：内容容器宽度六个页面六种、移动端全面破损、折叠控件失效、字号与触控目标偏小、全白卡片没有层级。旧站设计并不高级，但它每一屏只做一件事、点得到、看得清——这几件基本功新站丢了。

1旧站 vs 新站：正面比较

旧站用本地副本 + 本地模式（admin/admin）登录后截取，与新站同一浏览器、同一视口。

旧系统 · 词库1440px
优点：四张整块可点的大卡（约 200×90），标题 18px、说明 13px、动作「712 条 · 点击浏览」，一屏只有一个决策。移动端 2×2 网格正常可用。
新系统 · 词库1440px
问题：同屏 6 类控件（统计卡×4、分类 chips×5、搜索、视图切换、表格、分页）。行高 33px、正文 13px，掌握度条 4px 高且 0% 时完全不可见。

2移动端：新站的最大退步（P0）

孩子很可能用平板或手机。390px 宽下新站基本不可用，旧站却还能正常操作。

旧站 · 390px可用
顶部导航换行、2×2 卡片、16px 标题，整卡可点。
新站 · 390px破损
侧栏压成 76px 图标条（文字竖排）→ 页签每字一行 → 统计卡文字一字一行 → 表格右侧释义/掌握度/状态被裁且无法横滑。
P0-1

移动端六处具体破损与根因

  • 侧栏竖排字：AppLayout.vue:160 媒体查询只缩宽度到 76px，.s-name 没隐藏 → 38px 图标 + 文字挤在 60px 里
  • 页签每字一行：.tabs3 是 inline-flex 无 nowrap，5 个 tab 被压缩换行
  • 90 天日历变数字墙：固定 repeat(15, 1fr)，390px 下每列 16px → …9 101112131415
  • 入口卡一字一行：repeat(3, 1fr) 被压到每卡 60px
  • 表格右侧被裁：n-data-table 未设 scroll-x
  • 顶栏「管理/退出」竖排：.chip 缺 white-space:nowrap
修法：<768px 侧栏改抽屉（n-drawer）+ 页签横向滚动 + 表格卡片化 + 日历 7 列周视图 + 入口卡单列。

4功能性问题：折叠控件失效（P0）

阅读与听力的教材分组是核心入口，但箭头渲染成一个点，用户根本不知道该点哪里。

旧站 · 阅读有「展开」按钮
▶ Trainer 1 …　6 套·84 句　[展开]——箭头 + 文字按钮双保险，整行 44px 高。
新站 · 阅读只剩一个「·」
· Trainer 1：▸ 字符在当前字体下渲染成 2px 小点；无"展开"字样；听力页折叠头部宽度还与下方列表不一致。
P1

听力页：24 行流式平铺，没有分组边界

  • Test 1–6 各 4 个 Part 全部平铺，无卡片、无分隔线、无按钮
  • Part 名 13px 灰色，与题数同级 → 看不出主次
  • 折叠头部卡片（380px）比下方内容（620px）窄 → 像错位的标签
  • 展开/收起无过渡动画，内容"闪现"
修法：换 n-collapse（自带箭头/动画/无障碍），Test 作为二级折叠，Part 做成可点条目（右侧显示题数与「开始」）。

5视觉与可读性（P1）

P1-5

全白卡片症 + 图标三套混用

  • 侧栏学科用文字块（ABC / 文 / 123）、板块用 emoji（📖📚🎧🎤）、统计卡又是另一组 emoji → 同屏三套图标语言
  • 所有区块同为白底 + 1px 边 + 同一层阴影，卡片里套卡片
  • 空状态里的「去学习」与底部大按钮重复，两个都在抢注意力
  • 页面底色没铺（多数页纯白），白卡浮不起来
修法：统一 @vicons/ionicons5 线性图标（保留 🌱 仅作品牌位）；页面底色 #f7faf8；卡片只留两级；空状态只留一个主动作。
P1-7

空状态与创建表单混排（计划页）

  • 🌱 + "还没有计划…" 居中，仅隔 6px 就是「新计划天数 [30] ± [预览]」→ 视觉上像文字压住了输入框
  • 「预览」是白色普通按钮，与主操作等权
  • 页面 720px，右侧一半空着，两个卡片内容都偏上，下半屏全空
修法：空态与表单分成两块：空态卡（插画 + 说明 + 主按钮「创建计划」）→ 点击后展开天数输入（带动画）。
P1-4 / P1-6

字号偏小 · 表格密度过高 · 掌握度条不可见

  • 正文 13px、徽标 12px、分页 24px 见方 → 10–12 岁孩子偏吃力（旧站 14–16px）
  • 行高 33px，容易点错行；「去学习」按钮仅 28px 高
  • 掌握度条 4px、灰轨白填充 → 0% 时完全看不见，像坏了
  • 「未学」浅灰底浅灰字，对比度低于 WCAG AA
  • 列宽失衡：音标列被压窄、状态列 90px 只放两个字
修法：正文 15px / 行高 48px / 可点区 ≥40px；掌握度换 n-progress（8px + 百分比文字）；状态换 n-tag 三态；列宽固定。
P2-9 / P2-10

信息冗余：面包屑与页签说同一件事；42 考点全平铺

  • 面包屑「英语 / 口语 / 造句」+ 页签「计划 跟读 对话 复盘 造句」→ 同一信息占两行
  • 「加句」是操作而非分区，却占了一个页签位
  • 造句页：11 组分类 chips 折行成 5+5+1，视觉散乱；句型列表仅首条高亮，其余像正文
  • 阅读首页把 42 个考点全铺开，首屏几百个可点目标
修法：面包屑缩到两级（学科/板块）；「加句」移到教材页浮动按钮；造句分类改左侧窄列表 + 右侧内容；阅读考点改「10 天手风琴，默认只展开当前天」。

6优化方案：规则先行，再改页面

不是逐页"再调一调"，而是先把三条规则定死，页面改动才有收敛方向。

.main：padding 24/28，不设 max-width
.page 880px 居中 · 页内不再加 padding
字号上移一档标题 24 / 区块 18 / 正文 15 / 辅助 13 / 表格行高 48
卡片两级L1 白卡 16px 圆角细边；L2 浅底块 #f6faf7，禁卡中卡
按钮三层主 primary large · 次 secondary · 弱 quaternary，全站同一功能同一长相

9待你决策

① 移动端优先级孩子主要用电脑，还是平板/手机？若主要是平板横屏（≥1024px），P0-1 可降级为 P1，省 0.5 天。
