# 07 · 口语实时对话方案

> 目标：把自由对话做成「有教学策略、有记忆、有教材支撑」的 PET 口语陪练。
> 额度、付费闸门与管理页见 [08 AI 额度与计费](08-AI额度与计费.md)；功能编号见 [04](04-功能清单.md)。

## 1. 能力与边界

| 能力 | 实现 |
|---|---|
| 实时语音对话 | Qwen Realtime WebRTC，浏览器直连；服务端只做 SDP 交换与提示词 |
| 跟读评分 | 腾讯 SOE；135 句 / 45 包（每场景 3 句 B1+ 完整句）；录音在本地缓存，点「提交」时才签发 WSS URL，裁掉首尾静音后按官方 1:1 实时率整段上传（超过 1:1 会让引擎出错），不在朗读期间维持长连接；返回 `result` 为结构化对象，展示综合分 + 准确度/流利度/完整度 + 逐词漏读/增读/替换，生成改进建议；记录按「用户 + 天 + 句」只保留最高分和评价内容 |
| 造句 | 45 场景 × 2 题：中文提示 → 说英文 → 标准答案 + AI 修改建议 |
| 场景题库 | 45 个 PET 场景（Part1 14 / Part2 16 / Part3–4 15），独立页签 |
| 记忆与复盘 | 每轮回答即时改写为 B1 句；结束页内 5 分钟复盘；SRS 记忆曲线 |
| 练习时长 | 服务端按天累计；跟读/对话按麦克风开口秒数，造句按页面可见时间 |

**边界**：不做听力式答题/判分；口语 Key、对话音频不落盘；普通账号默认获得一次性总额度
（默认 ¥0.5），管理员可按账号调整；管理员账号不受额度限制。账单只做估算，不替代供应商对账。

## 2. 提示词分层（Prefix-Stack）

按变化频率分层，稳定层在前，兼顾教学与缓存命中。

| 层 | 内容 | 规模 / 更新 |
|---|---|---|
| L0 固定 | 角色 Pip、儿童安全红线、输出格式、单会话 12–15 分钟收尾 | ~800 tok，数月一改 |
| L1 教学法 | 三档脚手架、recast 不打断、CEFR B1 目标、PET 四维评分 | ~1200 tok，随教材 |
| L2 画像 | 能力/弱项/今日口语内容/长期记忆摘要 | ~600 tok，每日重建 |
| L3 场景 | 所选场景的话题、目标句型、必备词汇、Part 3 描述脚本 | ~800 tok，按场景注入 |
| L4 会话 | 本次对话轮次与工具调用结果 | 动态 |

L0–L1 全站共享，利于百炼隐式缓存命中；Realtime 在 `session.update` 一次性下发 L0–L3。

## 3. 三条记忆线

### 3.1 当天口语线（强关联）

只注入口语板块自身数据，**不混入词汇/阅读/听力**：

- 今天跟读的包与完成情况；
- 今天练过的场景（Part / 真题编号）；
- 最近 7 天高频错误表达；
- 今日计划任务（1–90 天计划按比例切分）。

### 3.2 长期记忆（压缩，不塞全文）

| 层级 | 存储 | 更新时机 |
|---|---|---|
| 会话摘要 | `speak_logs.summary`（≤150 tok） | 会话结束，文本模型生成 |
| 话题履历 | `speak_profiles.content`（JSON） | 结束累加，防重复话题 |
| 错误档案 | `speak_profiles.content`（issues 聚合 + 频次） | 结束归并 |

画像重建：每天首次会话前，用近 7 天摘要 + 话题 + issues + 当日数据生成，
缓存到 `speak_profiles`，跨天失效。

### 3.3 教材 / 场景线

| 部分 | 形式 | 场景包 |
|---|---|---|
| Part 1 | 个人访谈 | 14 个主题场景（问候、家庭、校园、日常、购物、饮食、爱好、居家、旅行、家乡、媒体、朋友、运动、环境） |
| Part 2 | 图片描述 | 16 个主题场景（课堂、图书馆、用餐、烹饪、球场、骑行、公园、海边、商场、生日、居家、电子设备、交通、观光、音乐、农场） |
| Part 3–4 | 讨论与延展 | 15 个话题场景（礼物、行李、地点、假期、校规、家务、英语学习、环境、健康、饮食、电影、派对、预算、手机、志愿） |

原始 85 题问答、131 篇范文、89 张真题图、55 个讨论话题保留在
`part1bank / essays / zhen2 / zhen34`，供追溯与后续扩充。
数据在 `data-src/speak/`，由 `tools/build_speak_v4.js` 生成 `speak.json` schema 5
（含难度/词数/focus）；加教材只改数据层。

## 4. 每日节奏与复盘

```text
5 min 跟读 → 10 min 造句 → 15 min 自由对话（10 min 对话 + 5 min 复盘）
```

- 只做计时与提示，不强制中断；三项都完成后当天打勾。
- 计划手动创建：选 1–90 天自动切分；已有计划只显示删除，新建/改长度重置打卡。
- 无计划时进入自由练习：从题库选句子组/句型/场景，不计时、不打卡、不写进度。
- 45 场景是独立题库，每日计划列出当天场景，可从计划或题库进入对话。

### 4.1 对话中的即时优化

```text
孩子说完一轮
  → POST /speak/improve：child_said → improved_en（保留本意）+ improved_cn + focus + dims
  → 气泡下方展示优化句：听示范（TTS）→ 就地跟读（SOE）→ 评分
  → 10 分钟后提示进入复盘（不强制）
```

### 4.2 结束复盘（页内，不设独立页）

```text
session_end（用会话计时计费，用开口秒数计时长）
  → 优化句经 /speak/review/import 落库（按 log + child_said 幂等）
  → 对话页底部展开 5 分钟复盘：逐句重读、评分、进记忆曲线
```

**SRS 规则**（与词汇/阅读错题同语义）：

- 维度 `dims = {grammar:三单, vocab:weekend, phrase:would_like}`；
- SOE ≥85 记为对，划掉对应维度；<60 记为错，该维度重欠并回 1 天；
- 间隔 1/2/4/7/15 天；全部维度划掉即毕业。

**三个复习出口**：到期复盘句、下次会话开场热身（`speak_boot` 注入）、结束报告中的待复习数。

## 5. 缓存与成本

| 层 | 策略 |
|---|---|
| 服务端 | L2 画像每日一份；L3 场景包进程内 LRU；总结落库不重算 |
| 百炼 Chat | L0+L1 固定前缀走隐式缓存；显式缓存仅用于 5 分钟内重建画像 |
| Realtime | 同一场景内复用连接，切换提示词用 `session.update`；半双工：AI 说话时静音麦克风 |
| TTS | `sha1(model + voice + text)` 磁盘缓存，命中不计费；静态 URL + `immutable` |

| 用途 | 模型 | 单价（2026-11 核实） |
|---|---|---|
| 实时对话 | `qwen3.8-omni-flash-realtime` | 音频输入 6 元/M tok、输出 12 元/M tok |
| 总结/画像/加词/改写 | `qwen3.8-flash` | 输入 0.8、输出 2.7 元/M tok |
| 跟读评分 | 腾讯 SOE 新版 | 资源包约 0.001 元/次；后付费 0.005 |
| TTS 示范 | `qwen3-tts-flash` | 约 0.08 元/千字符，仅按钮触发 |

每人每天约 30 分钟口语 ≈ **0.22–0.34 元**（月 7–10 元）。单价与预算存 `app_cfg`，管理页可改。

**为什么不换 ASR + LLM + TTS**：流水线约贵 4–5 倍，且 ASR 会把读错的词自动「纠正」成正确文本，
丢掉口语教学最核心的发音纠错；延迟也从 0.5–1 s 升到 2–3 s。Realtime 维持为主路径。

## 6. 教学脚手架与安全

- 三档策略：**等**（英文复述 + 简化，8 s）→ **提示**（中文关键词）→ **示范**（简单英文 + 中文对照）；绝不纠错打断。
- Function Call：`hint(word, cn, sentence)` 弹提示卡；`praise(score)` 显示奖励。
- 屏幕辅助：实时转写、「怎么说？」气泡、结束报告（新表达/纠正点/星星）。
- 安全：原始音频不落盘；L0 拒绝与学习无关的话题；单会话 12–15 分钟主动收尾。

## 7. 关键约束

- Key 只在服务端（`app_cfg`），SDP 交换才带 Key；前端只拿签名临时地址。
- WebRTC Offer 必须先 `pc.addTransceiver("audio", {direction: "sendrecv"})`：Offer 没有音频 m 线时服务端拒收，报 400「SDP format and content error」；麦克风在 `session.updated` 用 `transceiver.sender.replaceTrack()` 挂载（不重新协商），音频回流用 `pc.ontrack` 播放。
- 复盘句必须是孩子真实说过的改写，不臆造；原话与优化句并排。
- 合并语义、错题 dims 记账是红线，不得擅改（见 [AGENTS.md](../AGENTS.md)）。
