# 02 · 技术架构

> 更新：2026-11-24。选型决议见 [01 需求清单](01-需求清单.md) §5，部署见 [06 部署与运维](06-部署与运维.md)。

## 1. 总体架构

```text
浏览器（孩子 / 家长设备）
   │ HTTP(S)
   ▼
前置 TLS（路由器 / 飞牛反代）
   │
   ▼
nginx 容器 :8088
   ├─ /              → frontend/dist（Vue 静态产物）
   ├─ /data /audio   → 静态 JSON / 音频
   ├─ /media/math/   → NAS 课程视频（只读卷挂载，支持 Range；auth_request 校验媒体令牌）
   └─ /api/*         → api:8000（FastAPI）
                         ├─ REST /api/v1（auth / sync / words / speak / admin）
                         ├─ Qwen Realtime SDP 中转（仅信令，Key 不出服务端）
                         ├─ 本地 TTS → tts:8100（Piper 英/中双音色，仅 compose 内网）
                         └─ SQLite data/pet.db（WAL）
```

- 家庭 2–5 用户，nginx + api 常驻内存 < 1 GB；api 2 worker。本地 TTS sidecar 另限 640 MB（双音色实测约 270 MB），三者合计约 1.6 GB 上限。
- 实时语音（Qwen Realtime / 腾讯 SOE）由浏览器直连第三方，NAS 只承担静态与 REST；本地 TTS 在 NAS 内完成，音频经 api 缓存后由浏览器播放。

## 2. 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 + Vite + TypeScript | `<script setup lang="ts">` |
| 路由 / 状态 | vue-router + Pinia | 路由 `meta` 驱动布局与页签 |
| UI | Naive UI + `themeOverrides` | 业务样式只引用 Design Token |
| 前端测试 | vitest（jsdom） | 纯逻辑放 `src/core/` |
| 后端 | Python 3.12 + FastAPI + uvicorn | 路由薄，业务在 `services/` |
| ORM / 迁移 | SQLAlchemy 2 + Alembic | schema 只由 Alembic 管理，禁用 `create_all` |
| 数据库 | SQLite（WAL） | 单文件，备份=一致快照 |
| 认证 | JWT + argon2（兼容旧 bcrypt） | 邀请码注册，首账号 claim 为管理员 |
| AI | 阿里云百炼 Qwen Realtime / 文本模型；腾讯 SOE | Key 存 `app_cfg`，管理页配置 |
| 发音 | 本地 Piper（`deploy/tts` sidecar，英/中双音色） | 默认英文 `en_GB-alan-medium`、中文 `zh_CN-huayan-medium`，按文本是否含汉字自动选音色；固定内容预生成 + 按需缓存；失败回退浏览器 `speechSynthesis`。例外：跟读「听示范」走 Qwen TTS（缓存、免费） |
| 部署 | Docker Compose（nginx + api + tts） | NAS 生产与本地 Docker 同一份配置；Windows 开发用 `tools/dev_local.py`（FastAPI 直出 `dist`，8088） |

## 4. 前端分层

- **路由**：页面只在 `views/`；`meta`（subject/module/crumbs/tabs/width）驱动布局、面包屑、页签与内容宽度。
- **纯逻辑**：`src/core/` 不依赖组件，均有 vitest 覆盖；同步/合并**不得**写进组件。
- **HTTP**：统一走 `src/core/api.ts`，组件内禁止裸 `fetch`。
- **状态**：数据默认写 localStorage，联网后增量同步；快照键按用户隔离 `pet_sync_v2::<用户名>`。
  词汇测验的本轮进度另存 `pet_quiz_session::<作用域>`（自由 `free:<用户>`，计划测试按
  `plan:<用户>:<计划时间戳>:<天>:<词库>`），仅本地续做、不入同步。
- **样式**：Naive UI 主题在 `theme.ts`；业务颜色/字号/圆角只引用 `tokens.css`。

## 5. API（`/api/v1`）

| 组 | 端点 | 说明 |
|---|---|---|
| auth | `POST /auth/login` `POST /auth/refresh` `POST /auth/claim` `GET /auth/setup` | JWT、邀请码、首次初始化 |
| sync | `GET /sync/pull?since=` `POST /sync/push` | 带 `rev` 乐观锁；冲突 409 + 服务端最新 |
| words | `GET/POST /words` `PUT/DELETE /words/{id}` `POST /words/enrich` | 自加词；AI 补全词性/释义/例句 |
| speak | `/speak/boot` `/sdp` `/session_end` `/soe_url` `/log` `/days` `/plan` `/time` `/time/today` `/improve` `/review/*` `/help` `/check` `/tts` `/tts/demo` `/tts/file/{name}` `/tts/config` `/tts/local` `/ai_status` `/shadow/recent` `/usage_today` | 口语全套（详见 07）；付费接口服务端闸门；`POST /tts/local` 登录后本地合成（免费），`GET /tts/local` 公开只读缓存；`POST /tts/demo` 跟读听示范（登录即可、免费不记账、限流 30 次/分） |
| usage | `GET /usage/me?month=YYYY-MM` | 当前用户 AI 用量与预估费用（M4）：额度状态 + 今日/本周/所选月/今年汇总 + 逐日明细 |
| admin | `GET/PUT /admin/cfg` `GET /admin/usage` `GET /admin/usage/summary` `GET/POST /admin/codes` `GET /admin/users` | Key 配置、用量、邀请码、账号 AI 权限与额度 |
| admin · AI | `GET /admin/ai/overview` `GET/PUT /admin/ai/prices` `PUT /admin/users/{id}/ai` `POST /admin/users/{id}/ai/reset_alert` `GET /admin/usage/alerts` `GET /admin/usage/report` `GET /admin/usage/export` `GET/DELETE /admin/tts_cache` `POST /admin/test/{kind}` | 额度覆盖、月度报表/CSV、TTS 缓存、连通性测试 |
| health | `GET /healthz` | compose 探活 |

付费 AI 接口统一走 `require_paid_ai`：未开通返回 **403 `AI_NOT_ENABLED`**，一次性总额度用尽返回 **429 `AI_CREDIT_EXHAUSTED`**（`detail` 为对象，含 `code/message`）。管理员账号不受总额度拦截。免费接口（单词、阅读、听力、题库、跟读听读、`review/due` 等）不受影响。

免费例外：`POST /speak/tts/local`（本地 Piper，免费不计账）与 `POST /speak/tts/demo`（跟读听示范 Qwen，登录即可、不记用量、按用户 30 次/分钟限流）都不经过付费闸门。

阅读/听力/数学课程内容为静态 JSON 或静态媒体，答题与观看进度走 `sync`；没有独立的后端内容路由。

## 6. 数据模型

| 表 | 用途 | 关键点 |
|---|---|---|
| `users` | 账号 | `perms`（历史字段，不再参与鉴权）、`exam`（PET/KET）、`data_rev`、`ai_enabled`（AI 权限，新注册普通账号默认关）、`ai_credit_milli`（一次性总额度覆盖，NULL=全局默认） |
| `invite_codes` | 邀请码 | 首账号 claim 后由管理员发放 |
| `mastery` | 单词掌握维度 | 合并=并集 |
| `mistakes` | 错题本 + 记忆曲线 | `stage/due_at/repeats`；dims 记账 |
| `progress` | 阅读/听力/数学观看位置 | 合并=seen 并集 + idx 取大；数学 key `math:v:<lessonId>`，`seen` 含 `done` = 学完 |
| `plans` | 词汇/阅读计划 | 天数任意；阅读教材选择 `reading_books` |
| `custom_words` / `custom_sentences` | 手动加词/句 | 并入测验与错题体系 |
| `speak_logs` | 跟读/对话记录 | 摘要、逐句、issues；跟读带 `sentence_id` / `words` |
| `speak_days` | 口语打卡 | `shadow_done/make_done/talk_done` |
| `speak_plans` | 口语计划 | 手动 1–90 天；改长度重置打卡 |
| `speak_times` | 练习秒数 | 按天按模式，服务端累计 |
| `speak_profiles` | 学习者画像 | L2 提示词缓存，每日复用、会话总结后失效重建 |
| `speak_reviews` | 会后复盘句 | 与 `mistakes` 同构的 SRS |
| `usages` | AI 用量/费用 | 按人按天：Realtime 秒数/文本 token、SOE 次数、LLM token、TTS 次数/字符/缓存命中；`est_cost_milli` 按当前单价重算 |
| `usage_alerts` | 额度告警 | 总额度 80%/100% 按 `(user, period='total', period_key='all', stage)` 去重 |
| `ai_sessions` | Realtime 会话跟踪 | `open/closed/expired`；30 分钟未结束按上限补记 |
| `app_cfg` | Key 类配置 | 管理页编辑，接口只回尾 4 位；单价/默认总额度/TTS 上限/本地 TTS 配置（`speak.local`）也存这里 |

## 7. 同步与合并（红线，不得擅改）

```text
本地修改 → dirty 标记 → 防抖 1.2s push {rev, data}
                         ├─ 200 → 更新本地 rev
                         └─ 409 → merge(server, local) → 重试（≤3 次）
登录 / 每 45s → 静默 pull
```

- `mastery` / `mistakes`：并集；错题取「欠得多」的状态。
- `progress`：`seen` 并集、`idx` 取大。
- `plan`：同一代际完成状态并集；创建/删除/改天数按 `plan_updated_at` / `reading_updated_at` 取较新一侧（删除不会被旧计划并回来）。
- 本地快照按用户名隔离；离线可玩，联网补传；`__PET_LOCAL_ONLY` 可强制本地模式。
- 修改合并语义必须先写设计文档并获确认。

## 8. 数据构建链

```text
data-src/speak, data-src/math        （结构化源数据）
../PET/js/*.js                       （词库 / 阅读 / 听力旧站源）
   └─ tools/build_data.py / build_reading_v2.js / build_listening_v2.js /
      build_speak_v4.js / build_math.js
        └─ frontend/public/data/{banks,reading,listening,speak,math}.json
             └─ vite build → frontend/dist/data/（nginx 静态服务）
```

- 构建产物是生成文件，**改数据改 `data-src/` 后重新生成**，不手改 `public/data`。
- 音频/图片（`public/audio`、`public/img`）体积大，不进 git，部署时单独同步。
- 数学课程视频（三年级约 5.4 GB + 四年级约 17 GB）留在 NAS 媒体目录，由 nginx `/media/math/` 只读挂载直出，不随部署包上传。
  取流需要登录：前端用访问令牌换 6 小时媒体令牌拼到 `?mt=`，nginx `auth_request` 调
  `GET /api/v1/media/auth` 校验；无令牌直连 401。令牌放 URL 是为了兼容 AirPlay（电视端取流带不了 Cookie）。
- 听力数据与音频按 Part 切片；口语数据 schema v5（跟读句新增 `difficulty/words/focus/source/active`）见 [data-src/speak/README](../data-src/speak/README.md)。

## 9. 非功能约束

- 性能：家庭 2–5 并发，API P95 < 200 ms；静态资源走 nginx 缓存。
- 资源：nginx + api 常驻 ≤ 1 GB（N150 / 8 GB 富余）；本地 TTS sidecar 限额 640 MB、2 核（双音色实测约 270 MB）。
- 安全：内网/自用域名；TLS 前置终结；AI Key 只在服务端；密钥不入 git。
- 可维护：API 版本化、Alembic 迁移、前后端测试与构建必须绿。
