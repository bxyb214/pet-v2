# 02 · 技术架构

> 更新：2026-11-23。选型决议见 [01 需求清单](01-需求清单.md) §5，部署见 [06 部署与运维](06-部署与运维.md)。

## 1. 总体架构

```text
浏览器（孩子 / 家长设备）
   │ HTTP(S)
   ▼
前置 TLS（路由器 / 飞牛反代）
   │
   ▼
nginx 容器 :8088
   ├─ /              → frontend/dist（Vue 静态产物）
   ├─ /data /audio   → 静态 JSON / 音频
   ├─ /media/math/   → NAS 课程视频（只读卷挂载，支持 Range）
   └─ /api/*         → api:8000（FastAPI）
                         ├─ REST /api/v1（auth / sync / words / speak / admin）
                         ├─ Qwen Realtime SDP 中转（仅信令，Key 不出服务端）
                         └─ SQLite data/pet.db（WAL）
```

- 家庭 2–5 用户，常驻内存 < 1 GB；api 2 worker。
- 语音（Qwen Realtime / 腾讯 SOE）由浏览器直连第三方，NAS 只承担静态与 REST。

## 2. 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 + Vite + TypeScript | `<script setup lang="ts">` |
| 路由 / 状态 | vue-router + Pinia | 路由 `meta` 驱动布局与页签 |
| UI | Naive UI + `themeOverrides` | 业务样式只引用 Design Token |
| 前端测试 | vitest（jsdom） | 纯逻辑放 `src/core/` |
| 后端 | Python 3.12 + FastAPI + uvicorn | 路由薄，业务在 `services/` |
| ORM / 迁移 | SQLAlchemy 2 + Alembic | schema 只由 Alembic 管理，禁用 `create_all` |
| 数据库 | SQLite（WAL） | 单文件，备份=一致快照 |
| 认证 | JWT + argon2（兼容旧 bcrypt） | 邀请码注册，首账号 claim 为管理员 |
| AI | 阿里云百炼 Qwen Realtime / 文本模型；腾讯 SOE | Key 存 `app_cfg`，管理页配置 |
| 部署 | Docker Compose（nginx + api） | 本地与 NAS 同一份配置 |

## 4. 前端分层

- **路由**：页面只在 `views/`；`meta`（subject/module/crumbs/tabs/width）驱动布局、面包屑、页签与内容宽度。
- **纯逻辑**：`src/core/` 不依赖组件，均有 vitest 覆盖；同步/合并**不得**写进组件。
- **HTTP**：统一走 `src/core/api.ts`，组件内禁止裸 `fetch`。
- **状态**：数据默认写 localStorage，联网后增量同步；快照键按用户隔离 `pet_sync_v2::<用户名>`。
  词汇测验的本轮进度另存 `pet_quiz_session::<作用域>`（自由 `free:<用户>`，计划测试按
  `plan:<用户>:<计划时间戳>:<天>:<词库>`），仅本地续做、不入同步。
- **样式**：Naive UI 主题在 `theme.ts`；业务颜色/字号/圆角只引用 `tokens.css`。

## 5. API（`/api/v1`）

| 组 | 端点 | 说明 |
|---|---|---|
| auth | `POST /auth/login` `POST /auth/refresh` `POST /auth/claim` `GET /auth/setup` | JWT、邀请码、首次初始化 |
| sync | `GET /sync/pull?since=` `POST /sync/push` | 带 `rev` 乐观锁；冲突 409 + 服务端最新 |
| words | `GET/POST /words` `PUT/DELETE /words/{id}` `POST /words/enrich` | 自加词；AI 补全词性/释义/例句 |
| speak | `/speak/boot` `/sdp` `/session_end` `/soe_url` `/log` `/days` `/plan` `/time` `/time/today` `/improve` `/review/*` `/help` `/check` `/tts` `/usage_today` | 口语全套（详见 07） |
| admin | `GET/PUT /admin/cfg` `GET /admin/usage` `GET/POST /admin/codes` `GET /admin/users` `PUT /admin/users/{id}/perms` | Key 配置、用量、邀请码、权限 |
| health | `GET /healthz` | compose 探活 |

阅读/听力/数学课程内容为静态 JSON 或静态媒体，答题与观看进度走 `sync`；没有独立的后端内容路由。

## 6. 数据模型

| 表 | 用途 | 关键点 |
|---|---|---|
| `users` | 账号 | `perms`（`speak` / `!speak` / `!listen`）、`exam`（PET/KET）、`data_rev` |
| `invite_codes` | 邀请码 | 首账号 claim 后由管理员发放 |
| `mastery` | 单词掌握维度 | 合并=并集 |
| `mistakes` | 错题本 + 记忆曲线 | `stage/due_at/repeats`；dims 记账 |
| `progress` | 阅读/听力/数学观看位置 | 合并=seen 并集 + idx 取大；数学 key `math:v:<lessonId>`，`seen` 含 `done` = 学完 |
| `plans` | 词汇/阅读计划 | 天数任意；阅读教材选择 `reading_books` |
| `custom_words` / `custom_sentences` | 手动加词/句 | 并入测验与错题体系 |
| `speak_logs` | 跟读/对话记录 | 摘要、逐句、issues |
| `speak_days` | 口语打卡 | `shadow_done/make_done/talk_done` |
| `speak_plans` | 口语计划 | 手动 1–90 天；改长度重置打卡 |
| `speak_times` | 练习秒数 | 按天按模式，服务端累计 |
| `speak_profiles` | 学习者画像 | L2 提示词缓存，每日重建 |
| `speak_reviews` | 会后复盘句 | 与 `mistakes` 同构的 SRS |
| `usages` | AI 用量/费用 | 按人按天，只记录不限流 |
| `app_cfg` | Key 类配置 | 管理页编辑，接口只回尾 4 位 |

## 7. 同步与合并（红线，不得擅改）

```text
本地修改 → dirty 标记 → 防抖 1.2s push {rev, data}
                         ├─ 200 → 更新本地 rev
                         └─ 409 → merge(server, local) → 重试（≤3 次）
登录 / 每 45s → 静默 pull
```

- `mastery` / `mistakes`：并集；错题取「欠得多」的状态。
- `progress`：`seen` 并集、`idx` 取大。
- `plan`：同一代际完成状态并集；创建/删除/改天数按 `plan_updated_at` / `reading_updated_at` 取较新一侧（删除不会被旧计划并回来）。
- 本地快照按用户名隔离；离线可玩，联网补传；`__PET_LOCAL_ONLY` 可强制本地模式。
- 修改合并语义必须先写设计文档并获确认。

## 8. 数据构建链

```text
data-src/{vocab,reading,listening,speak,math}/
   └─ tools/build_*.js / build_data.py
        └─ frontend/public/data/{banks,reading,listening,speak,math}.json
             └─ vite build → frontend/dist/data/（nginx 静态服务）
```

- 构建产物是生成文件，**改数据改 `data-src/` 后重新生成**，不手改 `public/data`。
- 音频/图片（`public/audio`、`public/img`）体积大，不进 git，部署时单独同步。
- 数学课程视频（约 5.4 GB）留在 NAS 媒体目录，由 nginx `/media/math/` 只读挂载直出，不随部署包上传。
- 听力数据与音频按 Part 切片；口语数据 schema v3 见 [data-src/speak/README](../data-src/speak/README.md)。

## 9. 非功能约束

- 性能：家庭 2–5 并发，API P95 < 200 ms；静态资源走 nginx 缓存。
- 资源：全部容器常驻 ≤ 1 GB（N150 / 8 GB 富余）。
- 安全：内网/自用域名；TLS 前置终结；AI Key 只在服务端；密钥不入 git。
- 可维护：API 版本化、Alembic 迁移、前后端测试与构建必须绿。
